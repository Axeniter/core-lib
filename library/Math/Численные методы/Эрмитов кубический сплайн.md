# Эрмитовы кубические сплайны
## Условия
Это простейший тип кубического сплайна. Он строится локально на каждом отрезке и не требует решения систем уравнений.
Дано:
*   Сетка $\Delta: a = x_0 < x_1 < \dots < x_N = b$.
*   Шаг $h_i = x_{i+1} - x_i$.
*   Известны значения функции $f_i = f(x_i)$ и производной $f'_i = f'(x_i)$ во всех узлах.

## Построение
Построение на отрезке $[x_i, x_{i+1}]$:
Сплайн $S(x)$ ищется в виде полинома 3-й степени:
$$S(x) = a_{i0} + a_{i1}(x-x_i) + a_{i2}(x-x_i)^2 + a_{i3}(x-x_i)^3$$
Его производная:
$$S'(x) = a_{i1} + 2a_{i2}(x-x_i) + 3a_{i3}(x-x_i)^2$$
Условия для нахождения 4-х коэффициентов ($a_{i0}, a_{i1}, a_{i2}, a_{i3}$):
Записываются условия интерполяции на левом и правом концах отрезка:
1.  $S(x_i) = f_i$
2.  $S(x_{i+1}) = f_{i+1}$
3.  $S'(x_i) = f'_i$
4.  $S'(x_{i+1}) = f'_{i+1}$
Подставив $x = x_i$ и $x = x_{i+1}$, получаем систему:
$$
\begin{cases} 
a_{i0} = f_i \\ 
a_{i0} + a_{i1}h_i + a_{i2}h_i^2 + a_{i3}h_i^3 = f_{i+1} \\ 
a_{i1} = f'_i \\ 
a_{i1} + 2a_{i2}h_i + 3a_{i3}h_i^2 = f'_{i+1} 
\end{cases}
$$

Удобная запись через локальную переменную $t$:
Вводится замена $t = \frac{x - x_i}{h_i}$, где $t \in [0, 1]$ при $x \in [x_i, x_{i+1}]$.
Решение системы приводит к представлению сплайна через эрмитов базис:
$$S_3(x) = \varphi_1(t)f_i + \varphi_2(t)f_{i+1} + h_i\varphi_3(t)f'_i + h_i\varphi_4(t)f'_{i+1}$$
где базисные функции:
* $\varphi_1(t) = (1-t)^2(1+2t)$
* $\varphi_2(t) = t^2(3-2t)$
* $\varphi_3(t) = t(1-t)^2$
* $\varphi_{4}(t)=-t^{2}(1-t)$

## Погрешность
Если $f(x) \in C^4[a,b]$, то погрешность интерполяции на каждом отрезке имеет 4-й порядок: $\|S(x) - f(x)\| = O(h^4)$, где $h = \max h_i$.

## Замечание
Эрмитов сплайн принадлежит классу $C^1$ (непрерывен сам сплайн и его первая производная, но вторая производная терпит разрыв в узлах).
