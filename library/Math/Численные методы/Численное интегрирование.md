# Численное интегрирование (квадратурные формулы)
## Определение определенного интеграла
Пусть функция $f(x)$ определена на отрезке $[a, b]$.  
Разобьем отрезок на $n$ частей точками:
$$a = x_0 < x_1 < \dots < x_n = b$$
Обозначим:
- $\Delta x_i = x_i - x_{i-1}$ - длина $i$-го частичного отрезка
- $\xi_i \in [x_{i-1}, x_i)$ - произвольная точка на $i$-м полуинтервале
- $f(\xi_i)$ - значение функции в этой точке

Интегральная сумма:
$$S_n = \sum_{i=1}^n f(\xi_i) \Delta x_i$$

Определенный интеграл:
$$\int_a^b f(x) \, dx = \lim_{\max \Delta x_i \to 0} \sum_{i=1}^n f(\xi_i) \Delta x_i$$

Геометрический смысл: сумма площадей прямоугольников, аппроксимирующих площадь под кривой.

## Общее понятие погрешности
$$R = \int_a^b f(x) \, dx - \sum_{i=0}^n d_i y_i$$
$$R = O(h^r), \quad r > 0$$
где $h = \max_i h_i$ - максимальный шаг разбиения.

Погрешность можно представить как сумму локальных погрешностей на каждом отрезке:
$$R = \sum_{i=1}^n r_i, \quad r_i = \int_{x_{i-1}}^{x_i} f(x) \, dx - \sigma_i$$
где $\sigma_i$ - приближение интеграла на $i$-м отрезке по выбранной формуле.

## Квадратурные формулы
Общий вид квадратурной формулы:
$$\int_a^b f(x) \, dx \approx \sum_{i=0}^n \alpha_i y_i, \quad \text{где } y_i = f(x_i)$$

Коэффициенты $\alpha_i$ и узлы $x_i$ выбираются так, чтобы формула была точной для многочленов определенной степени.

Частный случай: формулы Ньютона-Котеса - получены интегрированием интерполяционного многочлена $L_n(x)$ на равномерной сетке.

## Метод прямоугольников
Разбиение отрезка $[a, b]$ на $n$ частей с шагом $h_i = x_i - x_{i-1}$.

### Формула левых прямоугольников
В качестве $\xi_i$ берем левый конец отрезка: $\xi_i = x_{i-1}$
$$\int_a^b f(x) \, dx \approx h_1 y_0 + h_2 y_1 + \dots + h_n y_{n-1}$$

### Формула правых прямоугольников
В качестве $\xi_i$ берем правый конец отрезка: $\xi_i = x_i$
$$\int_a^b f(x) \, dx \approx h_1 y_1 + h_2 y_2 + \dots + h_n y_n$$

### Формула средних прямоугольников
В качестве $\xi_i$ берем середину отрезка:
$$x_{i-\frac{1}{2}} = \frac{x_{i-1} + x_i}{2}$$
$$\int_a^b f(x) \, dx \approx \sum_{i=1}^n f\left(x_{i-\frac{1}{2}}\right) h_i$$
### Оценка погрешности метода средних прямоугольников
На отрезке $[x_{i-1}, x_i]$ разложим функцию в окрестности средней точки $x_{i-\frac{1}{2}} = \frac{x_{i-1} + x_i}{2}$:

$$f(x) = y_{i-\frac{1}{2}} + y'_{i-\frac{1}{2}} \left( x - x_{i-\frac{1}{2}} \right) + \frac{1}{2} y''_{i-\frac{1}{2}} \left( x - x_{i-\frac{1}{2}} \right)^2 + \frac{1}{6} y'''_{i-\frac{1}{2}} \left( x - x_{i-\frac{1}{2}} \right)^3 + O(h_i^4)$$

Интегрирование:
$$\int^{x_{i}}_{x_{i-1}}f(x)dx=y_{i-\frac{1}{2}}|^{x_{i}}_{x_{i-1}}+y'_{i-\frac{1}{2}}\frac{1}{2}\left( x-x_{i-\frac{1}{2}} \right)^2|^{x_{i}}_{x_{i-1}}+y''_{i-\frac{1}{2}} \frac{1}{6}\left( x-x_{i-\frac{1}{2}} \right)^3+\frac{1}{24}y'''_{i-\frac{1}{2}}\left( x-x_{i-\frac{1}{2}} \right)^4+O(h_{i}^5)$$
$$\left( x-x_{i-\frac{1}{2}} \right)|^{x_{i}}_{x_{i-1}}=\left(  \frac{x_{i}-x_{i-1}}{2}  \right)^{3}-\left( \frac{x_{i-1}-x_{i}}{2} \right)^3=\frac{h_{i}^3}{4}$$
$$\int_{x_{i-1}}^{x_i} f(x) \, dx = y_{i-\frac{1}{2}} \cdot h_i + \frac{h_i^3}{24} y''_{i-\frac{1}{2}} + O(h_i^5)$$

*Пояснение:* слагаемые с нечетными степенями $(x - x_{i-\frac{1}{2}})$ при интегрировании дают нуль из-за симметрии пределов.

Формула средних прямоугольников:
$$\delta_i^{\text{пр}} = y_{i-\frac{1}{2}} \cdot h_i$$

Локальная погрешность метода средних прямоугольников:
$$r_i^{\text{пр}} = \int_{x_{i-1}}^{x_i} f(x) \, dx - \delta_i^{\text{пр}} = \frac{h_i^3}{24} y''_{i-\frac{1}{2}} + O(h_i^5) = \frac{h_i^3}{24} y''(\xi_i), \quad \xi_i \in (x_{i-1}, x_i)$$

## Метод трапеций
На каждом частичном отрезке $[x_{i-1}, x_i]$ заменяем функцию прямой, проходящей через точки $(x_{i-1}, y_{i-1})$ и $(x_i, y_i)$.  
Площадь трапеции:
$$\delta_i = \frac{y_{i-1} + y_i}{2} h_i, \quad i = 1, 2, \dots, n$$

Общая формула:
$$\int_a^b f(x) \, dx \approx \frac{1}{2} \sum_{i=1}^n h_i (y_{i-1} + y_i)$$

Случай равномерной сетки ($h_i = h = \text{const}$):
$$\int_a^b f(x) \, dx \approx h \left( \frac{y_0 + y_n}{2} + \sum_{i=1}^{n-1} y_i \right)$$
### Оценка погрешности метода трапеций
Разложение значений в узлах:
$$y_{i-1} = y_{i-\frac{1}{2}} - \frac{h_i}{2} y'_{i-\frac{1}{2}} + \frac{h_i^2}{8} y''_{i-\frac{1}{2}} - \frac{h_i^3}{48} y'''_{i-\frac{1}{2}} + O(h_i^4)$$
$$y_i = y_{i-\frac{1}{2}} + \frac{h_i}{2} y'_{i-\frac{1}{2}} + \frac{h_i^2}{8} y''_{i-\frac{1}{2}} + \frac{h_i^3}{48} y'''_{i-\frac{1}{2}} + O(h_i^4)$$
Формула трапеций на одном отрезке:
$$\delta_i^{\text{тр}} = \frac{y_{i-1} + y_i}{2} h_i = y_{i-\frac{1}{2}} h_i + \frac{h_i^3}{8} y''_{i-\frac{1}{2}} + O(h_i^5)$$
Сравнение с точным значением интеграла:
$$\int_{x_{i-1}}^{x_i} f(x) \, dx = y_{i-\frac{1}{2}} h_i + \frac{h_i^3}{24} y''_{i-\frac{1}{2}} + O(h_i^5)$$
или:
$$\frac{y_{i-1}+y_i}{2}h_i - \frac{h_i^3}{12}y''_{i-\frac{1}{2}} + O(h_i^5)$$
Локальная погрешность метода трапеций:
$$r_i^{\text{тр}} = \int_{x_{i-1}}^{x_i} f(x) \, dx - \delta_i^{\text{тр}} = -\frac{h_i^3}{12} y''_{i-\frac{1}{2}} + O(h_i^5) = -\frac{h_i^3}{12} y''(\eta_i), \quad \eta_i \in (x_{i-1}, x_i)$$
## Комбинирование формул (правило Рунге)
Взвешенное среднее методов прямоугольников и трапеций дает более точную формулу:
$$I \approx \frac{2I_{\text{пр}} + I_{\text{тр}}}{3}$$
Локальная погрешность комбинированной формулы:
$$r_i = \frac{2r_i^{\text{пр}} + r_i^{\text{тр}}}{3} = O(h_i^5)$$
Это один из способов получения формулы Симпсона:
$$\int^b_{a}f(x)dx \approx \frac{h}{6}\left[ y_{0}+4\left( y_{\frac{1}{2}}+y_{\frac{3}{2}}+\dots+y_{n-\frac{1}{2}} \right) + 2(y_{1}+y_{2}+\dots+y_{n-1}) + y_{n} \right]$$

## Метод Симпсона (парабол)
Идея: на каждом сдвоенном отрезке $[x_{i-1}, x_{i+1}]$ заменяем функцию квадратичным интерполяционным многочленом (параболой), проходящим через три точки:
$$M_{i-1}(x_{i-1}, y_{i-1}), \quad M_i(x_i, y_i), \quad M_{i+1}(x_{i+1}, y_{i+1})$$
Интерполяционный многочлен Лагранжа 2-й степени:
$$L_2(x) = \frac{(x-x_i)(x-x_{i+1})}{(x_{i-1}-x_i)(x_{i-1}-x_{i+1})} y_{i-1} + \frac{(x-x_{i-1})(x-x_{i+1})}{(x_i-x_{i-1})(x_i-x_{i+1})} y_i + \frac{(x-x_{i-1})(x-x_i)}{(x_{i+1}-x_{i-1})(x_{i+1}-x_i)} y_{i+1}$$

Интегрирование на равномерной сетке ($h$ - шаг):
$$\int_{x_{i-1}}^{x_{i+1}} L_2(x) \, dx = \frac{1}{2h^2} \int_{x_{i-1}}^{x_{i+1}} \big[ (x-x_i)(x-x_{i+1}) y_{i-1} - 2(x-x_{i-1})(x-x_{i+1}) y_i + (x-x_{i-1})(x-x_i) y_{i+1} \big] dx$$

После интегрирования получаем формулу Симпсона на одном сдвоенном отрезке:
$$\int_{x_{i-1}}^{x_{i+1}} f(x) \, dx \approx \frac{h}{3} (y_{i-1} + 4y_i + y_{i+1})$$

Составная формула Симпсона (для четного числа отрезков $n$):
$$\int_a^b f(x) \, dx \approx \frac{h}{3} \left[ y_0 + 4(y_1 + y_3 + \dots + y_{n-1}) + 2(y_2 + y_4 + \dots + y_{n-2}) + y_n \right]$$

где $n$ - четное число, $h = \frac{b-a}{n}$.

## Глобальные оценки погрешности (для равномерной сетки)
### Метод прямоугольников
$$|R_{\text{пр}}| = \sum_{i=1}^n |r_i^{\text{пр}}| \leq \frac{h^3}{24} \sum_{i=1}^n |y''(\xi_i)| \leq \frac{h^3}{24} \cdot n \cdot M_2 = \frac{h^2}{24} (b-a) M_2 \quad \xi_{i}\in(x_{i-1},x_{i})$$
где $M_2 = \max_{a \leq x \leq b} |f''(x)|$, $h n = b-a$.
### Метод трапеций
$$|R_{\text{тр}}| \leq \frac{(b-a) h^2}{12} M_2$$
### Метод Симпсона
$$|R_{\text{с}}| \leq \frac{(b-a) h^4}{180} M_4$$
где $M_4 = \max_{a \leq x \leq b} |f^{(4)}(x)|$.

## Сводка формул (равномерная сетка $h=const$)
| Метод                      | Формула                                                                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Левые прямоугольники**   | $\displaystyle \int_a^b f(x)\,dx \approx h \sum_{i=0}^{n-1} y_i$                                                                             |
| **Правые прямоугольники**  | $\displaystyle \int_a^b f(x)\,dx \approx h \sum_{i=1}^{n} y_i$                                                                               |
| **Средние прямоугольники** | $\displaystyle \int_a^b f(x)\,dx \approx h \sum_{i=1}^{n} f\!\left(x_{i-\frac{1}{2}}\right)$                                                 |
| **Трапеции**               | $\displaystyle \int_a^b f(x)\,dx \approx h \left( \frac{y_0 + y_n}{2} + \sum_{i=1}^{n-1} y_i \right)$                                        |
| **Симпсон**                | $\displaystyle \int_a^b f(x)\,dx \approx \frac{h}{3} \left[ y_0 + y_n + 4\!\sum_{i \text{ нечёт}} y_i + 2\!\sum_{i \text{ чёт}} y_i \right]$ |

| Метод | Порядок точности | Глобальная оценка погрешности |
|-------|:---:|-------|
| **Левые / Правые прямоугольники** | $O(h)$ | $\displaystyle \frac{(b-a)h}{2} M_1$ |
| **Средние прямоугольники** | $O(h^2)$ | $\displaystyle \frac{(b-a)h^2}{24} M_2$ |
| **Трапеции** | $O(h^2)$ | $\displaystyle \frac{(b-a)h^2}{12} M_2$ |
| **Симпсон** | $O(h^4)$ | $\displaystyle \frac{(b-a)h^4}{180} M_4$ |
> **Обозначения:**
> $h = \dfrac{b-a}{n}$ — шаг сетки;
> $M_k = \max\limits_{a \le x \le b} \big| f^{(k)}(x) \big|$ — максимум модуля $k$-й производной на отрезке.
