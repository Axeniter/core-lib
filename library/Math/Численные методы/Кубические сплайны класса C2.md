# Кубические сплайны класса $C^2$ 
Это основной тип сплайнов, используемый для глобальной интерполяции.
## Определение
Функция $S(x)$ называется кубическим сплайном класса $C^2$ с узлами на сетке $\Delta$, если выполняются три условия:
1.  На каждом отрезке $[x_i, x_{i+1}]$ функция $S(x)$ — полином 3-й степени.
2.  $S(x)$ дважды непрерывно дифференцируема на всем $[a, b]$, то есть $S(x) \in C^2[a,b]$.
3.  (Условие интерполяции) $S(x_i) = f_i$ для всех $i = \overline{0, N}$.

## Подсчет параметров и условий
*   Всего $N$ отрезков $\to 4N$ неизвестных коэффициентов.
*   Условия интерполяции дают $N+1$ уравнение.
*   Условия непрерывности:
    *   Непрерывность $S(x)$ в $N-1$ внутреннем узле (учтено в п.3).
    *   Непрерывность $S'(x)$ в $N-1$ внутреннем узле.
    *   Непрерывность $S''(x)$ в $N-1$ внутреннем узле.
*   Итого: $(N+1) + 2(N-1) = 3N-1$ уравнение. Не хватает 2 уравнений до $4N$. Эти 2 недостающих уравнения задаются **краевыми условиями**.

## Краевые условия (замыкают систему)
1.  **Тип I (по наклону):** Заданы производные на концах: $S'(a) = f'(a)$ и $S'(b) = f'(b)$.
2.  **Тип II (по моменту):** Заданы вторые производные на концах: $S''(a) = f''(a)$ и $S''(b) = f''(b)$. Частный случай — **естественные краевые условия**: $S''(a) = S''(b) = 0$.
3.  **Тип III (периодические условия):** Для периодической функции $S'(a) = S'(b)$ и $S''(a) = S''(b)$.
4.  **Тип IV (условие not-a-knot):** Непрерывность третьей производной в точках $x_1$ и $x_{N-1}$: $S'''(x_1+0) = S'''(x_1-0)$ и $S'''(x_{N-1}+0) = S'''(x_{N-1}-0)$.

## Построение сплайна $C^2$ по наклонам
В этом подходе неизвестными являются значения первых производных в узлах: $m_i = S'(x_i)$.

**Представление на отрезке $[x_i, x_{i+1}]$ через $m_i$:**
Используя эрмитову форму, но с заменой $f'_i$ на $m_i$, получаем:
$$S(x) = f_i(1-t)^2(1+2t) + f_{i+1}t^2(3-2t) + m_i h_i t(1-t)^2 - m_{i+1} h_i t^2(1-t)$$
где $t = \frac{x - x_i}{h_i}$.

**Замыкание системы (условие непрерывности $S''$):**
Мы требуем, чтобы вторая производная не имела скачков во внутренних узлах: $S''(x_i + 0) = S''(x_i - 0)$.
Здесь $S''(x_i + 0)$ — это вторая производная от сплайна на отрезке $[x_i, x_{i+1}]$ в точке $x_i$ (где $t=0$), а $S''(x_i - 0)$ — от сплайна на отрезке $[x_{i-1}, x_i]$ в точке $x_i$ (где $t=1$).
1.  Дифференцируем $S(x)$ для отрезка $[x_i, x_{i+1}]$ и берем $t=0$:
    $$S''(x_i + 0) = \frac{6(f_{i+1} - f_i)}{h_i^2} - \frac{4m_i}{h_i} - \frac{2m_{i+1}}{h_i}$$
2.  Дифференцируем $S(x)$ для отрезка $[x_{i-1}, x_i]$ и берем $t=1$:
    $$S''(x_i - 0) = - \frac{6(f_i - f_{i-1})}{h_{i-1}^2} + \frac{2m_{i-1}}{h_{i-1}} + \frac{4m_i}{h_{i-1}}$$
3.  Приравниваем эти выражения и приводим подобные. Получаем систему с трехдиагональной матрицей:
    $$\lambda_i m_{i-1} + 2m_i + \mu_i m_{i+1} = c_i, \quad i = 1, \dots, N-1$$
    где:
    *   $\mu_i = \frac{h_{i-1}}{h_{i-1} + h_i}$
    *   $\lambda_i = 1 - \mu_i$
    *   $c_i = 3\left( \mu_i \frac{f_{i+1} - f_i}{h_i} + \lambda_i \frac{f_i - f_{i-1}}{h_{i-1}} \right)$
    *   В частном случае равномерной сетки ($h_i = h = const$), $\lambda_i = \mu_i = 1/2$, и уравнение принимает простой вид: $\frac{1}{2}m_{i-1} + 2m_i + \frac{1}{2}m_{i+1} = c_i$.

**Краевые условия (пример для наклонов Тип I):**
Добавляем два уравнения: $m_0 = f'(a)$ и $m_N = f'(b)$.
В общем виде система для $m_i$ ($i=\overline{0,N}$) записывается так:
$$
\begin{cases} 
2m_0 + \mu_0^* m_1 = c_0^* \\ 
\lambda_i m_{i-1} + 2m_i + \mu_i m_{i+1} = c_i, \quad i = \overline{1, N-1} \\ 
\lambda_N^* m_{N-1} + 2m_N = c_N^* 
\end{cases}
$$
Для случая задания $m_0$ и $m_N$ явно (Тип I), коэффициенты подбираются так, чтобы первое и последнее уравнения стали тождествами: $\mu_0^* = 0, c_0^* = 2m_0$ и $\lambda_N^* = 0, c_N^* = 2m_N$.

**Решение:**
Матрица системы трехдиагональна и обладает свойством строгого диагонального преобладания ($|2| > |\lambda_i| + |\mu_i| = 1$). Это гарантирует существование, единственность решения и устойчивость метода прогонки.

## Построение сплайна $C^2$ по моментам
Здесь неизвестными являются значения вторых производных в узлах: $M_i = S''(x_i)$.

**Представление на отрезке $[x_i, x_{i+1}]$ через $M_i$:**
Так как $S''(x)$ — линейная функция на отрезке, запишем ее по двум точкам:
$S''(x) = M_i(1-t) + M_{i+1}t$, где $t = \frac{x - x_i}{h_i}$.
Дважды интегрируя это выражение и используя условия интерполяции $S(x_i)=f_i, S(x_{i+1})=f_{i+1}$ для нахождения констант интегрирования, получаем:
$$S(x) = f_i(1-t) + f_{i+1}t - \frac{h_i^2}{6}t(1-t)[(2-t)M_i + (1+t)M_{i+1}]$$

**Замыкание системы (условие непрерывности $S'$):**
Требуем, чтобы первая производная не имела скачков во внутренних узлах: $S'(x_i + 0) = S'(x_i - 0)$.
1.  Находим $S'(x_i + 0)$ (производная на $[x_i, x_{i+1}]$ при $t=0$):
    $$S'(x_i + 0) = \frac{f_{i+1} - f_i}{h_i} - \frac{h_i}{6}(2M_i + M_{i+1})$$
2.  Находим $S'(x_i - 0)$ (производная на $[x_{i-1}, x_i]$ при $t=1$):
    $$S'(x_i - 0) = \frac{f_i - f_{i-1}}{h_{i-1}} + \frac{h_{i-1}}{6}(M_{i-1} + 2M_i)$$
3.  Приравниваем:
    $$\frac{f_{i+1} - f_i}{h_i} - \frac{f_i - f_{i-1}}{h_{i-1}} = \frac{h_i}{6}(2M_i + M_{i+1}) + \frac{h_{i-1}}{6}(M_{i-1} + 2M_i)$$
    Разделив на $\frac{h_{i-1}+h_i}{6}$, приходим к системе с такими же коэффициентами, как и для наклонов:
    $$\mu_i M_{i-1} + 2M_i + \lambda_i M_{i+1} = d_i$$
    где
    *   $\mu_i = \frac{h_{i-1}}{h_{i-1} + h_i}$, $\lambda_i = 1 - \mu_i$
    *   $d_i = 6 \cdot \frac{ \frac{f_{i+1} - f_i}{h_i} - \frac{f_i - f_{i-1}}{h_{i-1}} }{h_{i-1} + h_i}$ — **разделенная разность второго порядка**, умноженная на 6.

**Естественные краевые условия ($M_0 = M_N = 0$):**
Система сразу решается для внутренних моментов $M_1, \dots, M_{N-1}$, с автоматически заданными нулевыми граничными значениями.

**Погрешность:**
И для сплайна по наклонам, и по моментам, при достаточной гладкости функции $f(x) \in C^4[a,b]$, справедлива оценка:
$$ \|S^{(k)}(x) - f^{(k)}(x)\|_\infty \le C_k \|f^{(4)}\|_\infty h^{4-k}, \quad k = 0, 1, 2. $$
То есть порядок сходимости $O(h^4)$ для самой функции, $O(h^3)$ для первой производной и $O(h^2)$ для второй.

## Периодические кубические сплайны (метод циклической прогонки)
Применяются, когда функция периодична: $f_0 = f_N$ и $f_{N+1} = f_1$.
**Краевые условия периодичности:**
*   $S'(a) = S'(b)$ $\Rightarrow$ $m_0 = m_N$
*   $S''(a) = S''(b)$
*   Условно продлеваем сетку: $h_N = h_0$, $m_{N+1} = m_1$.
**Система для наклонов $m_i$:**
Записываем стандартные уравнения $\lambda_i m_{i-1} + 2m_i + \mu_i m_{i+1} = c_i$ для $i = \overline{1, N}$ с учётом периодичности:
Для $i=1$:
$$2m_1 + \mu_1 m_2 + \lambda_1 m_N = c_1$$
(здесь $m_0$ заменено на $m_N$)
Для $i = \overline{2, N-1}$:
$$\lambda_i m_{i-1} + 2m_i + \mu_i m_{i+1} = c_i$$
Для $i=N$:
$$\mu_N m_1 + \lambda_N m_{N-1} + 2m_N = c_N$$
(здесь $m_{N+1}$ заменено на $m_1$)
**Матрица системы:**
Имеет трёхдиагональный вид, но с двумя дополнительными элементами в правом верхнем и левом нижнем углах ("закольцовка"):
$$
\begin{pmatrix}
2 & \mu_1 & 0 & \dots & 0 & \lambda_1 \\
\lambda_2 & 2 & \mu_2 & \dots & 0 & 0 \\
0 & \lambda_3 & 2 & \dots & 0 & 0 \\
\vdots & \vdots & \vdots & \ddots & \vdots & \vdots \\
0 & 0 & 0 & \dots & 2 & \mu_{N-1} \\
\mu_N & 0 & 0 & \dots & \lambda_N & 2
\end{pmatrix}
\begin{pmatrix} m_1 \\ m_2 \\ m_3 \\ \vdots \\ m_{N-1} \\ m_N \end{pmatrix}
=
\begin{pmatrix} c_1 \\ c_2 \\ c_3 \\ \vdots \\ c_{N-1} \\ c_N \end{pmatrix}
$$
Такая матрица уже **не является строго трёхдиагональной**. Стандартный метод прогонки напрямую неприменим.

**Метод циклической прогонки:**
Решение ищется в виде линейной комбинации:
$$m_i = u_i + m_1 \cdot v_i, \quad i = \overline{1, N}$$
где:
*   $u_i$ — решение вспомогательной задачи с нулевым первым элементом и модифицированной правой частью,
*   $v_i$ — решение вспомогательной задачи с единичным первым элементом и нулевой правой частью.
Подстановка $i=N$ даёт уравнение для нахождения $m_1$:
$$m_N = u_N + m_1 v_N$$
А из периодичности $m_0 = m_N$ и исходного уравнения для $i=1$ можно найти $m_1$, а затем и все остальные $m_i$.

**Свойства:**
*   Матрица системы симметрична при равномерной сетке ($\lambda_i = \mu_i = 1/2$).
*   Метод циклической прогонки вычислительно эффективен ($O(N)$ операций).
*   Условие устойчивости: диагональное преобладание (выполнено, $|2| > |\lambda_i| + |\mu_i| = 1$).

## Краевое условие "not-a-knot" (непрерывность $S'''$)
Условие "отсутствия узла" означает, что точки $x_1$ и $x_{N-1}$ не являются настоящими узлами сплайна — в них третья производная непрерывна.
**Физический смысл:**
Сплайн ведёт себя так, как будто первые два (и последние два) отрезка описываются одним полиномом 3-й степени (нет "излома" третьей производной).
**Условия:**
$$S'''(x_1 + 0) = S'''(x_1 - 0) \quad \text{и} \quad S'''(x_{N-1} + 0) = S'''(x_{N-1} - 0)$$
**Формула для $S'''(x)$ на отрезке $[x_i, x_{i+1}]$ (через наклоны):**
$$S'''(x) = \frac{6}{h_i^2}\left( m_{i+1} + m_i - 2\frac{f_{i+1} - f_i}{h_i} \right)$$
(константа на всём отрезке, так как $S$ — полином 3-й степени).
**Вывод уравнений:**
**Левое условие ($p=1$):**
Приравниваем $S'''$ на $[x_0, x_1]$ и $[x_1, x_2]$:
$$\frac{1}{h_1^2}\left( m_2 + m_1 - 2\frac{f_2 - f_1}{h_1} \right) = \frac{1}{h_0^2}\left( m_1 + m_0 - 2\frac{f_1 - f_0}{h_0} \right)$$
После преобразований получаем уравнение, связывающее $m_0, m_1, m_2$:
$$m_0 + (1 - \gamma_0^2)m_1 - \gamma_0^2 m_2 = 2\left( \frac{f_1 - f_0}{h_0} - \gamma_0^2 \frac{f_2 - f_1}{h_1} \right)$$
где $\gamma_0 = \frac{h_0}{h_1}$.
**Правое условие ($p=N-1$):**
Приравниваем $S'''$ на $[x_{N-2}, x_{N-1}]$ и $[x_{N-1}, x_N]$:
$$-\gamma_N^2 m_{N-2} + (1 - \gamma_N^2)m_{N-1} + m_N = 2\left( \frac{f_N - f_{N-1}}{h_{N-1}} - \gamma_N^2 \frac{f_{N-1} - f_{N-2}}{h_{N-2}} \right)$$
где $\gamma_N = \frac{h_{N-1}}{h_{N-2}}$.

**Сведение к трёхдиагональной системе:**
Эти два уравнения содержат $m_0$ и $m_N$, которые не входят в основную систему ($i = \overline{1, N-1}$). Выражаем $m_0$ из левого условия и $m_N$ из правого, подставляем в уравнения для $i=1$ и $i=N-1$ соответственно.
После исключения получаем полную замкнутую систему относительно $m_1, \dots, m_{N-1}$:
Для $i=1$:
$$(1 - \gamma_0)m_1 + \gamma_0 m_2 = c_1^*$$
Для $i = \overline{2, N-2}$ — стандартные уравнения:
$$\lambda_i m_{i-1} + 2m_i + \mu_i m_{i+1} = c_i$$
Для $i=N-1$:
$$\gamma_N m_{N-2} + (1 + \gamma_N)m_{N-1} = c_{N-1}^*$$
где модифицированные правые части:
$$c_1^* = \frac{1}{3}c_1 + 2\gamma_0 \frac{f_2 - f_1}{h_1}$$
$$c_{N-1}^* = \frac{1}{3}c_{N-1} + 2\gamma_N \frac{f_{N-1} - f_{N-2}}{h_{N-2}}$$
После нахождения $m_1, \dots, m_{N-1}$ значения $m_0$ и $m_N$ вычисляются из соответствующих краевых уравнений.

**Преимущества условия "not-a-knot":**
*   Не требует знания производных на краях (в отличие от Типа I и II).
*   Часто даёт лучшую точность вблизи границ по сравнению с естественными условиями ($S''=0$).
