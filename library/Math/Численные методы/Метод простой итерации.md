# Метод простой итерации
## Идея
Уравнение $f(x) = 0$ приводится к эквивалентному виду:
$$x = \varphi(x)$$
Выбирается начальное приближение $x_0$. Далее строится итерационная последовательность:
$$x_{k+1} = \varphi(x_k), \quad k = 0, 1, 2, \dots$$
## Условие сходимости (теорема о сжимающем отображении)
Если $\varphi(x)$ определена и непрерывно дифференцируема на отрезке $[a, b]$, и выполнены условия:
1.  $\varphi(x) \in [a, b]$ при $x \in [a, b]$ (отображение в себя).
2.  $|\varphi'(x)| \le q < 1$ при $x \in [a, b]$ (сжатие с константой $q$).
Тогда на $[a, b]$ существует единственный корень $x^*$, и итерационная последовательность $x_{k+1} = \varphi(x_k)$ сходится к $x^*$ при любом $x_0 \in [a, b]$.

## Оценка погрешности
*   Априорная (до вычислений):
    $$|x_k - x^*| \le \frac{q^k}{1 - q}|x_1 - x_0|$$
*   Апостериорная (по двум соседним итерациям):
    $$|x_k - x^*| \le \frac{q}{1 - q}|x_k - x_{k-1}| \le \frac{1}{1 - q}|x_k - x_{k-1}|$$
    На практике процесс останавливают при $|x_k - x_{k-1}| < \varepsilon(1-q)$.

## Способы приведения к виду $x = \varphi(x)$
*   $x = x + \lambda f(x)$, где $\lambda$ подбирается из условия $|1 + \lambda f'(x)| < 1$.
*   Выразить $x$ из уравнения (например, если $f(x) = x - g(x)$, то $x = g(x)$).

## Скорость сходимости
*   Линейная, если $0 < |\varphi'(x^*)| < 1$.
*   Сверхлинейная/квадратичная, если $\varphi'(x^*) = 0$.
