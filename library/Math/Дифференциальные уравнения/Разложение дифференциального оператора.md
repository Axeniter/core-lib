# Разложение дифференциального оператора
## Дано
Линейный дифференциальный оператор:
$$Lx(t)=x^{(n)}(t)+a_{n-1}x^{(n-1)}(t)+\dots+a_{1}x'(t)+a_{0}x(t), \quad a_{j}\in \mathbb{R}$$
Характеристический многочлен:
$p(\lambda)=(\lambda-\lambda_{1})^{k_{1}}\dots(\lambda-\lambda_{m})^{k_{m}}$
$k_{1}+\dots+k_{m}=n$, $k_{j}\geq 1$
## Операторная запись
Пусть $D := \frac{d}{dt}$ — оператор дифференцирования, $I$ — тождественный оператор: $Ix = x$.

Тогда $(D - \lambda I)x = x' - \lambda x$.

**Примеры действия:**
*   $(D - \lambda_1 I)(D - \lambda_2 I)x = x'' - (\lambda_1 + \lambda_2)x' + \lambda_1 \lambda_2 x$.
*   $(D - \lambda I)^2 x = x'' - 2\lambda x' + \lambda^2 x$.

**Факторизация оператора $L$:**
$$Lx = x^{(n)} + a_{n-1}x^{(n-1)} + \dots + a_0 x = (D - \lambda_1 I)^{k_1} \dots (D - \lambda_m I)^{k_m} x$$
где $\lambda_j$ — корни характеристического многочлена кратности $k_j$.

## Обращение оператора первого порядка
Рассмотрим уравнение $(D - \lambda I)x = y$, т.е. $x' - \lambda x = y$.
Умножаем на $e^{-\lambda t}$:
$$(x' - \lambda x)e^{-\lambda t} = y e^{-\lambda t} \ \Rightarrow \ \frac{d}{dt}\left( e^{-\lambda t} x(t) \right) = y(t) e^{-\lambda t}$$
Интегрируем:
$$e^{-\lambda t} x(t) = x(0) + \int_0^t e^{-\lambda s} y(s) \, ds$$
$$x(t) = e^{\lambda t} \int_0^t e^{-\lambda s} y(s) \, ds + e^{\lambda t} x(0)$$

Обозначим **оператор $B_\lambda$**:
$$B_\lambda y(t) := e^{\lambda t} \int_0^t e^{-\lambda s} y(s) \, ds$$
Тогда общее решение: $x(t) = B_\lambda y(t) + C e^{\lambda t}$.

Краткая запись: $(D - \lambda I)^{-1} y = B_\lambda y + C e^{\lambda t}$.

## Решение однородного уравнения $(D - \lambda I)^k x = 0$

Последовательно "снимаем" операторы:
*   $(D - \lambda I)^{k-1} x = C_1 e^{\lambda t}$
*   $(D - \lambda I)^{k-2} x = C_1 t e^{\lambda t} + C_2 e^{\lambda t}$
*   $(D - \lambda I)^{k-3} x = C_1 \frac{t^2}{2} e^{\lambda t} + C_2 t e^{\lambda t} + C_3 e^{\lambda t}$
*   $\dots$
*   $x(t) = e^{\lambda t} \left( C_1 \frac{t^{k-1}}{(k-1)!} + \dots + C_{k-1} t + C_k \right)$

## Решение неоднородного уравнения операторным методом

$$Lx = f \ \Rightarrow \ (D - \lambda_1 I)^{k_1} \dots (D - \lambda_m I)^{k_m} x = f$$

Последовательно обращаем операторы, начиная с первого:
$$(D - \lambda_1 I)^{k_1-1} (D - \lambda_2 I)^{k_2} \dots (D - \lambda_m I)^{k_m} x = B_{\lambda_1} f + C_1 e^{\lambda_1 t}$$

**Пример.**
$$x'' - 4x = e^t$$
Характеристическое уравнение: $\lambda^2 - 4 = 0$, $\lambda = \pm 2$.
Операторная форма: $(D - 2I)(D + 2I)x = e^t$.

**Шаг 1.** Обращаем $(D - 2I)$:
$$(D + 2I)x = B_2(e^t) + C_1 e^{2t}$$
$$B_2(e^t) = e^{2t} \int_0^t e^{-2s} e^s ds = e^{2t} \int_0^t e^{-s} ds = e^{2t} (1 - e^{-t}) = e^{2t} - e^t$$
Получаем: $(D + 2I)x = C_1 e^{2t} - e^t$.

**Шаг 2.** Обращаем $(D + 2I)$:
$$x(t) = B_{-2}(C_1 e^{2t} - e^t) + C_2 e^{-2t}$$
$$B_{-2}(C_1 e^{2t} - e^t) = e^{-2t} \int_0^t e^{2s} (C_1 e^{2s} - e^s) ds = e^{-2t} \left( C_1 \cdot \frac{1}{4}(e^{4t} - 1) - \frac{1}{3}(e^{3t} - 1) \right)$$
Раскрываем: $= \tilde{C}_1 e^{2t} + \tilde{C}_1 e^{-2t} - \frac{1}{3} e^t + \frac{1}{3} e^{-2t}$.

**Общее решение:**
$$x(t) = -\frac{1}{3} e^t + \bar{C}_1 e^{2t} + \bar{C}_2 e^{-2t}$$

### Метод неопределённых коэффициентов (замечание)
Для правой части специального вида можно подобрать частное решение.

**Тот же пример:** $x'' - 4x = e^t$.
Ищем частное решение в виде $\hat{x}(t) = a e^t$ (так как $e^t$ не является решением однородного).
Подставляем:
$a e^t - 4a e^t = e^t \ \Rightarrow \ -3a = 1 \ \Rightarrow \ a = -\frac{1}{3}$.
Частное решение: $\hat{x}(t) = -\frac{1}{3} e^t$.

Общее решение: $x(t) = -\frac{1}{3} e^t + C_1 e^{2t} + C_2 e^{-2t}$.
