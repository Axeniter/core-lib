# Однородные уравнения первого порядка
## Определение однородной функции
Функция $M = M(x,y)$ называется **однородной степени $m$**, если для любого $t \neq 0$ выполняется:
$$M(tx, ty) = t^m M(x,y)$$

**Примеры:**
*   $M(x,y) = \sqrt[4]{x^8+y^8}$ — однородная степени $m=2$.
*   $M(x,y) = \frac{xy}{x^2+y^2}$ — однородная степени $m=0$.

## Случай 1: Явный вид $y' = f(x,y)$
Если $f(x,y)$ — однородная функция нулевой степени ($m=0$), то ее можно представить как функцию отношения $y/x$:
$$f(x,y) = f\left(1, \frac{y}{x}\right) = \varphi\left(\frac{y}{x}\right)$$
Уравнение принимает вид: $y' = \varphi\left(\frac{y}{x}\right)$.
**Замена:** $y = x \cdot z$, где $z = z(x)$. Тогда $y' = z + x z'$.
Подставляем в уравнение:
$$z + x z' = \varphi(z)$$
Получили уравнение с разделяющимися переменными:
$$x \frac{dz}{dx} = \varphi(z) - z$$

## Случай 2: Симметричный вид $M(x,y)dx+N(x,y)dy=0$
Если $M$ и $N$ — однородные функции одной и той же степени $m$, то, вынося $x^m$, получаем:
$$x^m M\left(1, \frac{y}{x}\right)dx + x^m N\left(1, \frac{y}{x}\right)dy = 0$$
Сокращаем $x^m$ (отдельно проверив, не является ли $x=0$ решением) и делаем замену $z = \frac{y}{x}$.
**Замечание:** Иногда удобнее использовать замену $z = \frac{x}{y}$.

**Пример:**
$$(x - y)dy = y dx$$
Функции $M(x,y) = -y$ и $N(x,y) = x-y$ — однородные степени $m=1$.
Удобно сделать замену $z = \frac{x}{y} \ (x = zy)$. Тогда $dx = y dz + z dy$.
Проверяем $y=0$ — является решением.
Подставляем в уравнение:
$(zy - y)dy = y(y dz + z dy)$
Делим на $y \neq 0$:
$(z - 1)dy = y dz + z dy$
$z dy - dy = y dz + z dy$
Приводим подобные: $-dy = y dz$.
Разделяем переменные и интегрируем:
$\frac{dy}{y} = -dz \ \Rightarrow \ \ln\left|\frac{y}{C}\right| = -z$.
$y=Ce^{-z}$
Возвращаемся к исходным переменным:
$y = Ce^{-x/y}$.

## Случай 3: Обобщенное однородное уравнение
$$y' = f\left( \frac{a_1 x + b_1 y + c_1}{a_2 x + b_2 y + c_2} \right)$$

### Подслучай 1
Если $c_1 = c_2 = 0$, то уравнение является однородным (см. Случай 1).

### Подслучай 2
Если хотя бы одна из констант $c_1, c_2$ не равна нулю и определитель $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} \neq 0$:
Система линейных уравнений имеет единственное решение $(\alpha, \beta)$:
$$
\begin{cases}
a_1 \alpha + b_1 \beta + c_1 = 0 \\
a_2 \alpha + b_2 \beta + c_2 = 0
\end{cases}
$$
Делаем замену (перенос начала координат):
$$x = t + \alpha$$
$$y = z + \beta$$
В новых переменных $dx = dt$, $dy = dz$, и уравнение становится однородным:
$$\frac{dz}{dt} = f\left( \frac{a_1 t + b_1 z}{a_2 t + b_2 z} \right)$$

### Подслучай 3
Если определитель $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} = 0$:
Строки матрицы коэффициентов линейно зависимы. Существует такое $\lambda$, что $a_1 = \lambda a_2$ и $b_1 = \lambda b_2$.
Тогда уравнение принимает вид:
$$y' = f\left( \frac{a_1 x + b_1 y + c_1}{\lambda (a_1 x + b_1 y) + c_2} \right) = \varphi(a_1 x + b_1 y)$$
Это уравнение сводится к уравнению с разделяющимися переменными заменой:
$$z = a_1 x + b_1 y$$

## Обобщенное однородное уравнение (Замечание)
Рассматривается уравнение в симметричной форме:
$$M(x,y)dx + N(x,y)dy = 0$$

Предположим, что функции $M$ и $N$ обладают свойством **обобщенной однородности**. Это означает, что существует такое число $\alpha$, что для любого $t \neq 0$ выполняются условия:
$$M(tx, t^\alpha y) = t^m M(x,y)$$
$$N(tx, t^\alpha y) = t^{m-\alpha+1} N(x,y)$$

В этом случае используется замена:
$$y = z \cdot x^\alpha$$
Эта замена сводит исходное уравнение к **уравнению с разделяющимися переменными**.
