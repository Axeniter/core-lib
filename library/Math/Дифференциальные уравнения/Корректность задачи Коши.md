# Корректность задачи Коши
## Задача Коши
Задача Коши для ОДУ первого порядка:
$$
\begin{cases}
x' = f(t,x), \quad t \in (0,T) \\
x(0) = x_0
\end{cases}
$$
где $x = x(t)$, $t \in [0, T]$.

Задача называется **корректной**, если выполняются три условия:
1.  **Существование** решения.
2.  **Единственность** решения.
3.  **Устойчивость** - непрерывная зависимость решения от начальных данных и параметров (при небольших изменениях параметров значения изменяются немного).

## Примеры некорректных задач
### 1. Нарушение существования глобального решения
$$
\begin{cases}
x' = x^2, \quad t \in (0,T) \\
x(0) = x_0 > 0
\end{cases}
$$
Разделяем переменные и интегрируем:
$$\int \frac{dx}{x^2} = \int dt \ \Rightarrow \ -\frac{1}{x} = t + C$$
Из начального условия $x(0) = x_0$ находим $C = -\frac{1}{x_0}$.
Выражаем решение:
$$\frac{1}{x} = -t + \frac{1}{x_0} \ \Rightarrow \ x(t) = \frac{1}{\frac{1}{x_0} - t}$$

**Анализ:** Решение представляет собой гиперболу с вертикальной асимптотой в точке $t = \frac{1}{x_0}$.
*   Если $T > \frac{1}{x_0}$ — решение **не существует** на всем интервале $[0, T]$ (уходит на бесконечность раньше).
*   Если $T < \frac{1}{x_0}$ — решение существует локально.
**Вывод:** Глобального решения задачи Коши не существует.

### 2. Нарушение единственности (континуум решений)
$$
\begin{cases}
x' = \sqrt{|x|}, \quad t \in (0, +\infty) \\
x(0) = 0
\end{cases}
$$
1.  **Очевидное решение:** $x(t) = 0$, $t \geq 0$.
2.  Ищем ненулевые решения. При $x > 0$:
    $$\frac{dx}{\sqrt{x}} = dt \ \Rightarrow \ 2\sqrt{x} = t + C$$
    При $C = 0$: $x(t) = \frac{1}{4}t^2$ — еще одно решение.
3.  **Семейство составных решений:** Будем искать решение такое, что $x(c) = 0$ для некоторого $c \geq 0$.
    Подставляя в общий интеграл: $0 = c + C \ \Rightarrow \ C = -c$.
    $$2\sqrt{x} = t - c \ \Rightarrow \ x(t) = \frac{1}{4}(t - c)^2$$

    Составляем кусочно-гладкую функцию, "склеивая" нулевое решение и параболу:
    $$ x(t) =
    \begin{cases}
    0, & 0 \leq t \leq c \\
    \frac{1}{4}(t-c)^2, & t > c
    \end{cases}
    $$
    В точке $t = c$ производная слева (0) совпадает с производной справа (0), так как $\frac{d}{dt}[\frac{1}{4}(t-c)^2]$ при $t=c$ равна нулю.

**Вывод:** Для **любого** $c \geq 0$ эта функция является решением. Получаем **континуальное множество** решений (мощность континуума).

**Обобщение:** Для уравнения $x' = |x|^\alpha$ при $0 < \alpha < 1$ условие Липшица нарушается, что и приводит к неединственности.

> Множество счетное, если оно равномощно множеству натуральных чисел
