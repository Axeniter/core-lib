# Уравнения в полных дифференциалах
## Дифференциал функции двух переменных
**Полный дифференциал** функции двух переменных $u = u(x,y)$:
$$du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy \quad \left( \text{обозначается также } u_x dx + u_y dy \right)$$
Если в области $G \subset \mathbb{R}^2$ выполняется $du = 0$, то $u(x,y) = \text{Const}$ для всех $(x,y) \in G$.

## Определение
Дифференциальное уравнение
$$M(x,y)dx + N(x,y)dy = 0$$
называется **уравнением в полных дифференциалах**, если существует такая функция $u = u(x,y)$, что ее полный дифференциал совпадает с левой частью уравнения:
$$du = M(x,y)dx + N(x,y)dy$$

Если это верно, то исходное уравнение равносильно $du(x,y) = 0$, откуда следует:
$$u(x,y) = C = \text{Const}$$
Это выражение называется **общим интегралом** уравнения, а функция $u$ — его **потенциалом**.

Это равносильно выполнению условий:
$$\frac{\partial u}{\partial x} = M(x,y), \quad \frac{\partial u}{\partial y} = N(x,y)$$
А также условию равенства смешанных производных (критерий полного дифференциала):
$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

## Теорема (критерий уравнения в полных дифференциалах)
Пусть $D$ — область на плоскости $\mathbb{R}^2$, и функции $M, N, \frac{\partial M}{\partial y}, \frac{\partial N}{\partial x}$ непрерывны в $D$ (т.е. принадлежат классу $C(D)$).

Тогда условие существования потенциала $u$ для которого $du=Mdx+Ndy$ эквивалентно выполнению равенства:
$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \quad \text{в области } D.$$

### Доказательство
**Необходимость ($\Rightarrow$):**
Если существует $u$, такая что $u_x = M$ и $u_y = N$, то смешанные производные равны:
$$u_{xy} = \frac{\partial M}{\partial y}, \quad u_{yx} = \frac{\partial N}{\partial x}$$
Поскольку для непрерывно дифференцируемых функций $u_{xy} = u_{yx}$, получаем $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$.

**Достаточность ($\Leftarrow$):**
Пусть $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$. Найдем функцию $u$ из условия $u_x = M$:
$$u(x,y) = \int M(x,y) \, dx + \varphi(y)$$
(При интегрировании по $x$ константа интегрирования может зависеть от $y$, поэтому возникает неизвестная функция $\varphi(y)$).

Продифференцируем найденное выражение по $y$ и приравняем к $N$:
$$\frac{\partial u}{\partial y} = \frac{\partial}{\partial y} \left( \int M(x,y) \, dx \right) + \varphi'(y) = N(x,y)$$
Отсюда выражаем производную $\varphi'(y)$:
$$\varphi'(y) = N(x,y) - \int \frac{\partial M}{\partial y}(x,y) \, dx$$

Проверим, что правая часть действительно зависит только от $y$. Для этого возьмем от нее производную по $x$:
$$\frac{\partial}{\partial x} \left( N(x,y) - \int \frac{\partial M}{\partial y}(x,y) \, dx \right) = \frac{\partial N}{\partial x}(x,y) - \frac{\partial M}{\partial y}(x,y) = 0$$
(Равенство нулю как раз и следует из нашего исходного условия $M_y = N_x$).
Интегрируя $\varphi'(y)$ по $y$, находим $\varphi(y)$ и окончательно восстанавливаем $u(x,y)$.

## Пример 1. Нахождение потенциала интегрированием
$$(3x^2 + 6xy^2)dx + (6x^2y + 4y^3)dy = 0$$
1.  **Проверка:** $M_y = 12xy$, $N_x = 12xy$. Условие $M_y = N_x$ выполнено.
2.  **Восстановление $u$:**
    $$u = \int M dx = \int (3x^2 + 6xy^2) dx = x^3 + 3x^2y^2 + \varphi(y)$$
3.  **Нахождение $\varphi(y)$:**
    $$u_y = 6x^2y + \varphi'(y) = N = 6x^2y + 4y^3$$
    Следовательно, $\varphi'(y) = 4y^3 \ \Rightarrow \ \varphi(y) = y^4$.
4.  **Общий интеграл:**
    $$x^3 + 3x^2y^2 + y^4 = C$$

## Замечание (Способ интегрирования по ломаной)
Для уравнения в полных дифференциалах можно найти потенциал $u(x,y)$, выбрав фиксированную точку $(x_0, y_0)$ и проинтегрировав дифференциальное выражение вдоль ломаной, идущей сначала параллельно оси $x$, а затем параллельно оси $y$:
$$u(x,y) = \int_{x_0}^{x} M(s, y_0) \, ds + \int_{y_0}^{y} N(x, s) \, ds$$

## Пример 2. Интегрирование по ломаной
$$e^{-y}dx - (2y + xe^{-y})dy = 0$$
1.  **Проверка:** $M_y = -e^{-y}$, $N_x = -e^{-y}$. Условие выполнено.
2.  **Интегрирование по ломаной** (возьмем $x_0 = 0, y_0 = 0$):
$$u(x,y) = \int_{0}^{x} e^{-0} ds - \int_{0}^{y} (2s + xe^{-s}) ds$$
$$= x - \left[ s^2 - xe^{-s} \right]_{0}^{y} = x - y^2 + xe^{-y} - x = -y^2 + xe^{-y}$$
3.  **Общий интеграл:**
$$xe^{-y} - y^2 = C$$

## Пример 3. Выделение интегрируемых комбинаций
Часто уравнение можно решить, не прибегая к общим формулам, а группируя слагаемые в известные дифференциалы.
$$2xy \, dx + (x^2 - 3y^2)dy = 0$$
Перегруппируем:
$$(y \cdot 2x \, dx + x^2 \, dy) - 3y^2 dy = 0$$
Заметим, что $y \cdot d(x^2) + x^2 dy = d(x^2y)$, а $-3y^2 dy = -d(y^3)$.
Уравнение принимает вид:
$$d(x^2y) - d(y^3) = 0 \ \Rightarrow \ d(x^2y - y^3) = 0$$
Общий интеграл:
$$x^2y - y^3 = C$$

## Интегрирующий множитель
Если уравнение $M(x,y)dx + N(x,y)dy = 0$ **не** является уравнением в полных дифференциалах, иногда удается подобрать такую ненулевую функцию $\mu = \mu(x,y)$, называемую **интегрирующим множителем**, что после умножения на нее уравнение становится уравнением в полных дифференциалах:
$$(\mu M)_y = (\mu N)_x$$

Поиск $\mu$ в общем случае — сложная задача (уравнение в частных производных). Рассмотрим два важных частных случая.

### Случай 1. Интегрирующий множитель для линейного уравнения
Линейное уравнение $y' + p(x)y = q(x)$ всегда можно представить в симметричной форме:
$$(p(x)y - q(x))dx + dy = 0$$
Его интегрирующий множитель зависит только от $x$:
$$\mu(x) = e^{\int p(x)dx}$$
После умножения получаем:
$$\frac{d}{dx}\left( e^{\int p(x)dx} y(x) \right) = q(x)e^{\int p(x)dx}$$

### Случай 2. Интегрирующий множитель вида $\mu = \mu(x)$
Пусть $\mu$ зависит только от $x$. Раскроем условие полного дифференциала:
$$\frac{\partial}{\partial y}(\mu M) = \frac{\partial}{\partial x}(\mu N)$$
$$\mu \frac{\partial M}{\partial y} = \mu_x N + \mu \frac{\partial N}{\partial x}$$
$$\mu_x N = \mu \left( \frac{\partial M}{\partial y} - \frac{\partial N}{\partial x} \right)$$
Тогда мы можем найти $\mu$, если выражение
$$\frac{M_y - N_x}{N}$$
**не зависит от $y$** (т.е. является функцией только от $x$).

## Пример 4. Интегрирующий множитель
$$(x^2 + y^2 + x)dx + ydy = 0$$
Проверка: $M_y = 2y$, $N_x = 0$. Это не уравнение в полных дифференциалах.
Вычислим отношение:
$$\frac{M_y - N_x}{N} = \frac{2y - 0}{y} = 2$$
Оно не зависит от $y$. Значит, существует интегрирующий множитель $\mu(x)$.
Уравнение для него:
$$(\mu(x)\cdot(x^{2}+y^{2}+x))_{y}=(\mu(x)\cdot y)_{x}$$
$$2y\cdot\mu(x)=\mu'(x)\cdot y$$
$$\frac{\mu_x}{\mu} = 2 \ \Rightarrow \ \mu'(x) = 2\mu(x) \ \Rightarrow \ \mu(x) = e^{2x}$$
Умножаем исходное уравнение на $\mu$:
$$e^{2x}(x^2 + y^2 + x)dx + e^{2x}y dy = 0$$
Восстанавливаем потенциал $u$:
$u_y = e^{2x}y \ \Rightarrow \ u = \frac{1}{2}e^{2x}y^2 + \varphi(x)$.
$u_x = e^{2x}y^2 + \varphi'(x) = M = e^{2x}(x^2 + y^2 + x)$.
Сокращаем $e^{2x}y^2$, получаем $\varphi'(x) = e^{2x}(x^2 + x)$.
Интегрируем: $\varphi(x) = \frac{1}{2}x^2 e^{2x}$ (можно проверить дифференцированием).
Общий интеграл:
$$\frac{1}{2}e^{2x}y^2 + \frac{1}{2}x^2 e^{2x} = C \ \Rightarrow \ e^{2x}(x^2 + y^2) = C$$
