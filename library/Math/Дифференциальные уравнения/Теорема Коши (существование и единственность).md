# Теорема Коши (существование и единственность)
## Теорема
**Задача Коши:**
$$
\begin{cases}
x' = f(t, x), \quad t \in (0, T) \\
x(0) = x_0
\end{cases}
$$

**Теорема.**
Пусть функция $f: [0,T] \times \{ |x - x_0| \leq b \} \to \mathbb{R}$:
1.  **Непрерывна**.
2.  **Ограничена:** $|f| \leq M$.
3.  **Липшицева по $x$:** $|f(t, x_1) - f(t, x_2)| \leq L \cdot |x_1 - x_2|$ для всех $x_{1,2}$ из области (с константой $L > 0$).

Тогда существует **единственное** решение задачи Коши на промежутке $[0, T_1]$, где:
$$T_1 = \min\left\{ T, \frac{b}{M}, \frac{1}{2L} \right\}$$

## Доказательство
1.  **Эквивалентное интегральное уравнение:**
    Задача Коши равносильна интегральному уравнению:
    $$x(t) = x_0 + \int_0^t f(s, x(s)) \, ds$$

2.  **Выбор пространства и множества:**
    Рассмотрим банахово пространство $E = C[0, T_1]$ с нормой $\|x\| = \max_{0 \leq t \leq T_1} |x(t)|$.
    Определим замкнутое множество (шар) $K$:
    $$K = \{x=x(t), t \in [0, T_{1}], x \in E : \|x - x_0\| \leq b \} = \overline{K}$$

3.  Определение оператора ($\mathcal{A}: K \to E$):
    $$\mathcal{A}x(t) = x_0 + \int_0^t f(s, x(s)) \, ds$$
    Задача свелась к поиску неподвижной точки: $x = \mathcal{A}x$.

4.  **Проверка $\mathcal{A}: K \to K$:**
    Для $x \in K$:
    $$\| \mathcal{A}x - x_0 \| = \max_{0 \leq t \leq T_1} \left| \int_0^t f(s, x(s)) ds \right| \leq M \cdot T_1 \leq M \cdot \frac{b}{M} = b$$
    Значит, $\mathcal{A}x \in K$.

5.  **Проверка сжатия:**
    Для $x_1, x_2 \in K$:
    $$\|\mathcal{A}x_1 - \mathcal{A}x_2\| = \max_{0 \leq t \leq T_1} \left| \int_0^t (f(s, x_1(s)) - f(s, x_2(s))) ds \right|$$
    По условию Липшица:
    $$|f(s, x_1(s)) - f(s, x_2(s))| \leq L |x_1(s) - x_2(s)| \leq L \|x_1 - x_2\|$$
    Тогда:
    $$\left| \int_0^t (f(s, x_1) - f(s, x_2)) ds \right| \leq \int_0^t L \|x_1 - x_2\| ds = L \cdot t \cdot \|x_1 - x_2\| \leq L \cdot T_1 \cdot \|x_1 - x_2\|$$
    Константа сжатия $q = L \cdot T_1$. По выбору $T_1 \leq \frac{1}{2L}$, имеем $q \leq \frac{1}{2} < 1$. Оператор $\mathcal{A}$ является сжатием.

6.  По принципу Банаха существует единственная неподвижная точка $x_* \in K$ — искомое решение. $\square$

## Пример
Дано интегральное уравнение (эквивалентное задаче $x'=x$, $x(0)=1$):
$$x(t) = 1 + \int_0^t x(s) \, ds, \quad t \in [0, T]$$
Строим итерации, начиная с $x_0(t) = 1$:
*   $x_1(t) = \mathcal{A}x_0 = 1 + \int_0^t 1 \, ds = 1 + t$
*   $x_2(t) = \mathcal{A}x_1 = 1 + \int_0^t (1 + s) ds = 1 + t + \frac{1}{2}t^2$
*   $x_3(t) = \mathcal{A}x_2 = 1 + \int_0^t \left(1 + s + \frac{s^2}{2}\right) ds = 1 + t + \frac{t^2}{2!} + \frac{t^3}{3!}$
*   $\dots$
*   $x_n(t) = \sum_{k=0}^n \frac{1}{k!} t^k$
При $n \to \infty$ последовательность сходится в $C[0,T]$ к точному решению $x(t) = e^t$.
