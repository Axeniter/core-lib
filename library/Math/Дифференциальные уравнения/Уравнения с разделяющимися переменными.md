# Уравнения с разделяющимися переменными
Записываются в виде:
$$M_1(x) \cdot M_2(y)dx + N_1(x) \cdot N_2(y)dy = 0$$
Делим обе части на $M_2(y) \cdot N_1(x)$ (при условии, что знаменатель не равен нулю):
$$\frac{M_1(x)}{N_1(x)}dx + \frac{N_2(y)}{M_2(y)}dy = 0$$
**Важно:** Отдельно рассматриваем возможные решения, которые мы могли потерять при делении, то есть корни уравнений:
$$N_1(x) = 0, \quad M_2(y) = 0$$
В виде системы:
$$
\left[
\begin{array}{l}
  \dfrac{M_1(x)}{N_1(x)}\,dx + \dfrac{N_2(y)}{M_2(y)}\,dy = 0, \quad N_{1}(x)\cdot M_{2}(y)\neq 0 \\[8pt]
  N_{1}(x)=0 \\
  M_{2}(y)=0
\end{array}
\right.
$$
Интегрируем полученное равенство:
$$\int \frac{M_1(x)}{N_1(x)}dx + \int \frac{N_2(y)}{M_2(y)}dy = \text{Const}$$

**Частный случай:** $y' = f(x)g(y)$
$$\frac{dy}{dx} = f(x)g(y) \quad \Rightarrow \quad \frac{dy}{g(y)} = f(x)dx$$
Аналогично, не забываем проверить корни уравнения $g(y)=0$.
$$\int \frac{dy}{g(y)}=\int f(x)dx$$
## Замечание (Замена для линейного аргумента)
Для уравнения вида $y' = f(ax + by + k), \ (a,b,k = \text{const})$, вводится замена:
$$z = ax + by + k$$
Дифференцируем по $x$: $z' = a + b \cdot y' = a + b \cdot f(z)$. Получаем уравнение с разделяющимися переменными $z' = a + b \cdot f(z)$.

**Пример:**
$$y' = 2x - y$$
Замена: $z = 2x - y \quad \Rightarrow \quad z' = 2 - y' = 2 - z$.
Решаем уравнение $\frac{dz}{dx} = 2 - z$:
1.  Проверяем $z=2$ — является решением.
2.  Интегрируем при $z \neq 2$:
    $\int \frac{dz}{2-z} =\int dx$
    $-\ln|2-z| = x - \ln|C| \ \Rightarrow \ \ln\left|\frac{z-2}{C}\right| = -x \ \Rightarrow \ z-2 = Ce^{-x}$.
Обратная замена: $2x - y - 2 = Ce^{-x} \ \Rightarrow \ y = 2x - 2 - Ce^{-x}$.
Общее решение: $y=2(x-1)+Ce^{-x}$
Случай $C=0$ дает нам ранее найденное решение $z=2$, т.е. $y=2x-2$.
