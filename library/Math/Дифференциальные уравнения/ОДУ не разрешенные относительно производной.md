# ОДУ не разрешенные относительно производной
**Общий вид:**
$$F(x, y, y') = 0$$

## Общие понятия
В отличие от уравнений вида $y' = f(x,y)$, здесь производная может входить нелинейно, что приводит к многозначности.

**Пример:**
$$(y')^2 = 4x^2$$
Извлекаем корень, получаем два дифференциальных уравнения:
$$y' = 2x \quad \text{или} \quad y' = -2x$$
Их решения:
$$y = x^2 + C_1 \quad \text{и} \quad y = -x^2 + C_2$$
Общее решение можно записать в виде произведения:
$$(y - x^2 - C_1)(y + x^2 - C_2) = 0$$

**Задача Коши:**
1.  **а.** Условие $y(1) = 1$.
    Подставляем в оба семейства:
    *   $1 = 1^2 + C_1 \Rightarrow C_1 = 0$. Решение: $y = x^2$.
    *   $1 = -1^2 + C_2 \Rightarrow C_2 = 2$. Решение: $y = 2 - x^2$.
    Ответ: $y = x^2$ и $y = 2 - x^2$.

2.  **б.** Условие $y(0) = 0$.
    *   $0 = 0^2 + C_1 \Rightarrow C_1 = 0$. Решение: $y = x^2$.
    *   $0 = -0^2 + C_2 \Rightarrow C_2 = 0$. Решение: $y = -x^2$.
    Решения различны, но в точке $(0,0)$ они пересекаются.

## Неполные уравнения (метод введения параметра)
В этих случаях одна из переменных отсутствует в явном виде.

### Случай 1: Уравнение вида $F(x, y') = 0$
Пусть удалось найти параметризацию, удовлетворяющую уравнению $F(\varphi(t),\psi(t))=0$:
$$x = \varphi(t), \quad y' = \psi(t)$$
Тогда $dy = y' dx = \psi(t) \varphi'(t) dt$.
Общее решение в параметрическом виде:
$$
\begin{cases}
x = \varphi(t) \\
y = \int \psi(t) \varphi'(t) \, dt
\end{cases}
$$

**Частный случай:** Если можно выразить $x = \varphi(y')$, то берем $t = y'$.
$$x = \varphi(t), \quad y' = t$$
$$dy = t \, dx = t \varphi'(t) dt$$
Решение:
$$
\begin{cases}
x = \varphi(t) \\
y = \int t \varphi'(t) \, dt = t\varphi(t) - \int \varphi(t) dt
\end{cases}
$$

**Пример:**
$$x = (y')^3 + y'$$
Вводим параметр $t = y'$:
$$x = t^3 + t$$
$$dy = t \, dx = t \, d(t^3 + t) = t(3t^2 + 1)dt = (3t^3 + t)dt$$
$$y = \int (3t^3 + t) dt = \frac{3}{4}t^4 + \frac{1}{2}t^2 + C$$
Ответ в параметрической форме:
$$
\begin{cases}
x = t^3 + t \\
y = \frac{3}{4}t^4 + \frac{1}{2}t^2 + C
\end{cases}
$$

### Случай 2: Уравнение вида $F(y, y') = 0$
Пусть найдена параметризация для которой $F(\varphi(t),\psi(t))=0$:
$$y = \varphi(t), \quad y' = \psi(t)$$
Используем связь $y' = \frac{dy}{dx}$, откуда
$$dx = \frac{dy}{y'} = \frac{\varphi'(t) dt}{\psi(t)} \quad (\psi(t) \neq 0)$$
Решение:
$$
\begin{cases}
x = \int \frac{\varphi'(t)}{\psi(t)} \, dt \\
y = \varphi(t)
\end{cases}
$$

**Частный случай:** Если можно выразить $y = \varphi(y')$, то берем $t = y'$.
$$y = \varphi(t), \quad y' = t = \frac{dy}{dx} = \frac{\varphi'(t)dt}{dx} \Rightarrow dx = \frac{\varphi'(t)}{t} dt$$
Решение:
$$
\begin{cases}
x = \int \frac{\varphi'(t)}{t} dt \\
y = \varphi(t)
\end{cases}
$$

**Пример:**
$$y^{2/3} + (y')^{2/3} = 1$$
Параметризуем, полагая $y^{1/3} = \cos t$, $(y')^{1/3} = \sin t$:
$$y = \cos^3 t, \quad y' = \sin^3 t$$
Находим $dx$:
$$dx = \frac{dy}{y'} = \frac{d(\cos^3 t)}{\sin^3 t} = \frac{-3 \cos^2 t \sin t \, dt}{\sin^3 t} = -3 \frac{\cos^2 t}{\sin^2 t} dt = -3 \cot^2 t \, dt$$
$$x = -3 \int \cot^2 t \, dt = -3 \int \left( \frac{1}{\sin^2 t} - 1 \right) dt = 3(\cot t + t) + C$$
Ответ (плюс проверка случая $\sin t = 0 \Rightarrow y'=0, y=1$):
$$
\begin{cases}
x = 3(\cot t + t) + C \\
y = \cos^3 t
\end{cases}
$$

## Уравнение Лагранжа
**Общий вид:**
$$y = x \cdot \varphi(y') + \psi(y')$$
Вводим параметр $t = y'$:
$$y = x \varphi(t) + \psi(t)$$
Дифференцируем обе части по $x$, помня, что $y' = t$ и $t = t(x)$:
$$\frac{dy}{dx} = t = \varphi(t) + x \varphi'(t) \frac{dt}{dx} + \psi'(t) \frac{dt}{dx}$$
Переносим $\varphi(t)$ влево:
$$t - \varphi(t) = \frac{dt}{dx} (x \varphi'(t) + \psi'(t))$$
При условии $t - \varphi(t) \neq 0$, переворачиваем дробь и получаем линейное уравнение относительно $x$ как функции от $t$:
$$\frac{dx}{dt} = \frac{\varphi'(t)}{t - \varphi(t)} \cdot x + \frac{\psi'(t)}{t - \varphi(t)}$$
Решив его, найдем $x = x(t, C)$. Затем $y$ находим из исходного уравнения.

**Пример:**
$$y = 2x y' - 4(y')^3$$
Пусть $t = y'$, тогда:
$$y = 2xt - 4t^3$$
Дифференцируем:
$$t = 2t + 2x \frac{dt}{dx} - 12t^2 \frac{dt}{dx}$$
$$-t = (2x - 12t^2) \frac{dt}{dx}$$
1.  **Особый случай:** $t = 0 \Rightarrow y' = 0 \Rightarrow y = 0$ (решение).
2.  При $t \neq 0$, "переворачиваем" уравнение, чтобы получить зависимость $x(t)$:
    $$\frac{dx}{dt} = -\frac{2}{t}x + 12t$$
    Это линейное уравнение. Решаем, например, подстановкой $x = uv$:
    *   $u'v + v'u + \frac{2}{t}uv = 12t$
    *   Выбираем $u' = -\frac{2}{t}u \ \Rightarrow \ u = t^{-2}$.
    *   Тогда $v' \cdot t^{-2} = 12t \ \Rightarrow \ v' = 12t^3 \ \Rightarrow \ v = 3t^4 + C$.
    *   $x = uv = 3t^2 + \frac{C}{t^2}$.
Подставляем найденный $x$ в выражение для $y$:
$$y = 2t\left(3t^2 + \frac{C}{t^2}\right) - 4t^3 = 6t^3 + \frac{2C}{t} - 4t^3 = 2t^3 + \frac{2C}{t}$$
Ответ в параметрической форме:
$$
\begin{cases}
x = 3t^2 + \frac{C}{t^2} \\
y = 2t^3 + \frac{2C}{t}
\end{cases}
$$
(плюс особое решение $y=0$).

## Уравнение Клеро
**Общий вид (частный случай Лагранжа при $\varphi(y') = y'$):**
$$y = x y' + \psi(y')$$
Вводим параметр $t = y'$:
$$y = xt + \psi(t)$$
Дифференцируем:
$$t = t + x \frac{dt}{dx} + \psi'(t) \frac{dt}{dx}$$
Сокращаем $t$:
$$(x + \psi'(t)) \frac{dt}{dx} = 0$$
Произведение равно нулю, отсюда два семейства решений:

1.  **Общее решение:** $\frac{dt}{dx} = 0 \ \Rightarrow \ t = C = \text{const}$.
    Подставляем в уравнение:
    $$y = Cx + \psi(C)$$
    Это семейство прямых.

2.  **Особое решение:** $x + \psi'(t) = 0$.
    Получаем параметрическое решение (огибающую семейства прямых):
    $$
    \begin{cases}
    x = -\psi'(t) \\
    y = -t\psi'(t) + \psi(t)
    \end{cases}
    $$

**Пример:**
$$y = x y' + \frac{1}{y'}$$
Здесь $\psi(t) = \frac{1}{t}$.
Записываем уравнение с параметром: $y = xt + \frac{1}{t}$.
Дифференцируем: $t=t+x \frac{dt}{dx}- \frac{1}{t^{2}} \frac{dt}{dx}$
Получаем: $\frac{dt}{dx}\left( x-\frac{1}{t^{2}} \right)=0$
1.  **Общее решение:** $t = C \ (C \neq 0)$.
    $$y = Cx + \frac{1}{C}$$
2.  **Особое решение:**
    $$\psi'(t) = -\frac{1}{t^2}$$
    Находим $x = -\psi'(t) = \frac{1}{t^2}$, $y = -t\left(-\frac{1}{t^2}\right) + \frac{1}{t} = \frac{2}{t}$.
    Исключаем параметр $t$:
    $t = \frac{2}{y} \ \Rightarrow \ x = \frac{1}{(2/y)^2} = \frac{y^2}{4} \ \Rightarrow \ y^2 = 4x$.
    Это парабола.

### Геометрический смысл особого решения
Особое решение $y^2 = 4x$ является **огибающей** семейства прямых $y = Cx + \frac{1}{C}$.

**Проверка:**
Уравнение касательной к верхней полупараболе $y = 2\sqrt{x}$ в точке $x_0$:
$$y = 2\sqrt{x_0} + \frac{1}{\sqrt{x_0}}(x - x_0) = \frac{1}{\sqrt{x_0}}x + \sqrt{x_0}$$
Если обозначить $C = \frac{1}{\sqrt{x_0}}$, то уравнение касательной принимает вид $y = Cx + \frac{1}{C}$.
Следовательно, все прямые из общего решения касаются параболы $y^2 = 4x$.
