# Метод неопределённых коэффициентов
## Постановка задачи
Рассматривается линейное неоднородное уравнение с постоянными коэффициентами:
$$Lx(t) = x^{(n)} + a_{n-1}x^{(n-1)} + \dots + a_0 x = f(t), \quad a_j \in \mathbb{R}$$

Правая часть — **квазимногочлен**:
$$f(t) = e^{\mu t} P(t)$$
где $P(t)$ — многочлен, $\deg P = q$, $\mu \in \mathbb{C}$.

Характеристический многочлен оператора $L$:
$$p(\lambda) = (\lambda - \lambda_1)^{k_1} \dots (\lambda - \lambda_m)^{k_m}$$

## Случай 1. Нерезонансный ($\mu \neq \lambda_j$ для всех $j$)
Показатель $\mu$ **не совпадает** ни с одним из корней характеристического многочлена ($\mu \neq \lambda_{j}$, $j= \overline{1,m}$).

### Обоснование операторным методом
$$Lx = (D - \lambda_1 I)^{k_1} \dots (D - \lambda_m I)^{k_m} x = e^{\mu t} P(t)$$

Обращаем первый оператор:
$$(D - \lambda_1 I)^{k_1-1} (D - \lambda_2 I)^{k_2} \dots x = (D - \lambda_1 I)^{-1} (e^{\mu t} P(t))$$
$$= e^{\lambda_1 t} \int_0^t e^{(\mu - \lambda_1)s} P(s) \, ds + C_1 e^{\lambda_1 t}$$

Так как $\mu \neq \lambda_1$, интеграл от произведения экспоненты на многочлен даёт **снова квазимногочлен с той же экспонентой $e^{\mu t}$ и многочленом той же степени $q$**:
$$= e^{\mu t} P_1(t) + C_1 e^{\lambda_1 t}, \quad \deg P_1 = q = \deg P$$

Повторяя процесс $n$ раз, на каждом шаге степень многочлена при $e^{\mu t}$ не повышается.

**Вывод:** Существует частное решение вида
$$\hat{x}(t) = e^{\mu t} Q(t)$$
где $Q(t)$ — многочлен, $\deg Q = q$.

### Пример 1
$$x'' - 4x = e^t (t+1)$$
Характеристическое уравнение: $\lambda^2 - 4 = 0$, $\lambda = \pm 2$.
$\mu = 1$, $\mu \neq \pm 2$ — **нерезонанс**. $q = 1$.

Ищем частное решение: $\hat{x}(t) = e^t (at + b)$.
$\hat{x}'(t) = e^t (at + a + b)$
$\hat{x}''(t) = e^t (at + 2a + b)$

Подставляем в уравнение:
$e^t(at + 2a + b) - 4e^t(at + b) = e^t(t+1)$
$(at + 2a + b) - 4(at + b) = t+1$
$-3a t + (2a - 3b) = t + 1$

Приравниваем коэффициенты:
$t^1$: $-3a = 1 \ \Rightarrow \ a = -\frac{1}{3}$
$t^0$: $2a - 3b = 1 \ \Rightarrow \ -\frac{2}{3} - 3b = 1 \ \Rightarrow \ -3b = \frac{5}{3} \ \Rightarrow \ b = -\frac{5}{9}$

Частное решение: $\hat{x}(t) = -e^t \left( \frac{1}{3}t + \frac{5}{9} \right)$.

Общее решение:
$$x(t) = -e^t \left( \frac{1}{3}t + \frac{5}{9} \right) + C_1 e^{2t} + C_2 e^{-2t}$$

### Пример 2
$$x'' - 3x' + 2x = \cos t = \mathrm{Re}(e^{it})$$
Характеристическое уравнение: $\lambda^2 - 3\lambda + 2 = 0$, $\lambda = 1, 2$.
$\mu = i \neq 1, 2$ — **нерезонанс**. $q = 0$.

Ищем частное решение в комплексной форме: $\hat{x}(t) = e^{it} \cdot a$ ($a \in \mathbb{C}$).
$\hat{x}' = i a e^{it}$, $\hat{x}'' = -a e^{it}$.
Подставляем:
$-a - 3ia + 2a = 1 \ \Rightarrow \ a(1 - 3i) = 1 \ \Rightarrow \ a = \frac{1}{1-3i} = \frac{1+3i}{10}$

$\hat{x}(t) = \frac{1+3i}{10} (\cos t + i \sin t)$.
Берём вещественную часть:
$$\mathrm{Re}\ \hat{x}(t) = \frac{1}{10} \cos t - \frac{3}{10} \sin t$$

Общее решение:
$$x(t) = \frac{1}{10}(\cos t - 3 \sin t) + C_1 e^t + C_2 e^{2t}$$

### Пример 3
$$x'' - 3x' + 2x = 2\cos t + e^{3t}$$
По **принципу суперпозиции**: если $Lx_1 = f_1$ и $Lx_2 = f_2$, то $L(x_1 + x_2) = f_1 + f_2$.

Для $2\cos t$ частное решение (из примера 2, умножаем на 2):
$\hat{x}_1 = \frac{2}{10}(\cos t - 3\sin t) = \frac{1}{5}(\cos t - 3\sin t)$.

Для $e^{3t}$: $\mu = 3 \neq 1, 2$, ищем $\hat{x}_2 = e^{3t} a$.
$9a - 9a + 2a = 1 \ \Rightarrow \ a = \frac{1}{2}$.

Общее решение:
$$x(t) = \frac{1}{5}(\cos t - 3\sin t) + \frac{1}{2} e^{3t} + C_1 e^t + C_2 e^{2t}$$

## Случай 2. Резонанс ($\mu$ совпадает с корнем характеристического многочлена)
Пусть $\mu = \lambda_*$, где $\lambda_*$ — корень кратности $k$ характеристического многочлена $p(\lambda)$.

### Обоснование операторным методом
При обращении оператора $(D - \mu I)$ на квазимногочлен $e^{\mu t} P(t)$ экспоненты "схлопываются":
$$B_\mu(e^{\mu t} P(t)) = e^{\mu t} \int_0^t P(s) \, ds = e^{\mu t} (P_1(t) + C_1)$$
где $\deg P_1 = \deg P + 1$. **Степень многочлена повышается на единицу.**

Функции $e^{\mu t}, t e^{\mu t}, \dots, t^{k-1} e^{\mu t}$ являются решениями однородного уравнения (порождаются корнем кратности $k$). При каждом обращении оператора $(D - \mu I)$ степень многочлена при $e^{\mu t}$ растёт, пока мы не "выйдем" за пределы кратности.

**Вывод:** Существует частное решение вида
$$\hat{x}(t) = e^{\mu t} \, t^k \, Q(t)$$
где $Q(t)$ — многочлен, $\deg Q = \deg P = q$.

### Пример 4
$$x'' + x = \cos t = \mathrm{Re}(e^{it})$$
Характеристическое уравнение: $\lambda^2 + 1 = 0$, $\lambda = \pm i$.
$\mu = i$ — корень кратности $k = 1$. **Резонанс.** $q = 0$.

Ищем частное решение в виде $\hat{x}(t) = e^{it} \, t \, a$ ($a \in \mathbb{C}$).
$\hat{x}'(t) = a e^{it} (it + 1)$
$\hat{x}''(t) = a e^{it} (i(it+1) + i) = a e^{it} (2i - t)$

Подставляем в уравнение $x'' + x = e^{it}$:
$a e^{it} (2i - t) + a e^{it} t = e^{it} \ \Rightarrow \ a \cdot 2i = 1 \ \Rightarrow \ a = \frac{1}{2i} = -\frac{i}{2}$

$\hat{x}(t) = -\frac{i}{2} t (\cos t + i \sin t)$.
Берём вещественную часть:
$$\mathrm{Re}\ \hat{x}(t) = \frac{1}{2} t \sin t$$

Общее решение:
$$x(t) = \frac{1}{2} t \sin t + C_1 \cos t + C_2 \sin t$$

### Физическая модель: резонанс
**Модель "грузик на пружинке":**
*   $m$ — масса грузика.
*   $k$ — жёсткость пружины.
*   $F(t)$ — внешняя сила, зависящая от времени.

Уравнение движения (второй закон Ньютона):
$$m x'' = -k x + F(t) \ \Rightarrow \ x'' + \omega^2 x = \frac{1}{m} F(t), \quad \omega^2 = \frac{k}{m}$$

**Собственная частота** колебаний системы: $\omega = \sqrt{\frac{k}{m}}$.

Характеристическое уравнение: $\lambda^2 + \omega^2 = 0$, $\lambda = \pm i\omega$.
Общее решение однородного уравнения: $x_0(t) = C_1 \cos \omega t + C_2 \sin \omega t$.

**Задача о резонансе**
Внешняя сила с частотой, равной собственной:
$$x'' + \omega^2 x = \varepsilon \cos(\omega t), \quad x(0) = 0, \ x'(0) = 0$$

Это **резонанс**: $\mu = i\omega$ — корень кратности $k=1$.
Ищем частное решение в виде $\hat{x}(t) = e^{i\omega t} \, t \, a$.
Из предыдущего (с заменой $1 \to \omega$): $\hat{x}(t) = \frac{\varepsilon}{2\omega} t \sin(\omega t)$.

Общее решение:
$$x(t) = \frac{\varepsilon}{2\omega} t \sin(\omega t) + C_1 \cos \omega t + C_2 \sin \omega t$$

Начальные условия:
$x(0) = C_1 = 0$
$x'(0) = \frac{\varepsilon}{2\omega} (\sin 0 + 0) + C_2 \omega = 0 \ \Rightarrow \ C_2 = 0$

**Решение задачи Коши:**
$$x(t) = \frac{\varepsilon}{2\omega} \, t \sin(\omega t) = A_\varepsilon(t) \sin(\omega t)$$

Амплитуда колебаний $A_\varepsilon(t) = \frac{\varepsilon}{2\omega} t$ **линейно растёт** со временем: $A_\varepsilon(t) \to +\infty$ при $t \to +\infty$.

**Это и есть явление резонанса** — неограниченный рост амплитуды колебаний при совпадении частоты внешней силы с собственной частотой системы.
