# Линейные уравнения первого порядка
**Общий вид:**
$$y' + p(x) \cdot y = q(x)$$
где $p(x)$ и $q(x)$ — известные функции.

Случаи:
*   **Однородное уравнение:** $q(x) = 0$.
*   **Неоднородное уравнение:** $q(x) \neq 0$.
*   **Линейный дифференциальный оператор:** $Ly = y' + p(x)y$.
    *   Свойство линейности: $L(C_1 y_1 + C_2 y_2) = C_1 Ly_1 + C_2 Ly_2$.

## Случай 1. Однородное линейное уравнение ($q=0$)
$$y' + p(x)y = 0$$

Умножаем обе части на интегрирующий множитель $e^{\int p(x)dx}$:
$$y' e^{\int p(x)dx} + y \cdot p(x) e^{\int p(x)dx} = 0$$
Левая часть сворачивается в производную произведения:
$$\frac{d}{dx} \left( e^{\int p(x)dx} \cdot y(x) \right) = 0$$
Интегрируя, получаем **общее решение однородного уравнения**:
$$y(x) = C \cdot \exp\left( -\int p(x)dx \right)$$

**Пример 1:**
$$y' + xy = 0$$
Общее решение:
$$y = C e^{-x^2/2}$$

## Случай 2. Неоднородное линейное уравнение ($q \neq 0$)
$$y' + p(x)y = q(x)$$

### Способ 1. Метод вариации постоянной (метод Лагранжа)
1. Находим общее решение соответствующего однородного уравнения:
$$y_{\text{одн}} = C \cdot \exp\left( -\int p(x)dx \right)$$
2. Ищем решение неоднородного уравнения в том же виде, но считаем $C$ неизвестной функцией $C(x)$:
$$y = C(x) \cdot \exp\left( -\int p(x)dx \right)$$
3. Подставляем это выражение в исходное неоднородное уравнение:
$$C'(x)\exp\left( -\int p(x)dx \right)-C(x)p(x)\exp\left( -\int p(x)dx \right)+p(x)C(x)\exp(-\int p(x)dx)=q(x)$$
Слагаемые с $C(x)$ без производной сократятся, и останется:
$$C'(x) \cdot \exp\left( -\int p(x)dx \right) = q(x)$$
4. Находим $C'(x)$:
$$C'(x) = q(x) \cdot \exp\left( \int p(x)dx \right)$$
5. Интегрируем, чтобы найти $C(x)$, и подставляем результат в формулу для $y$.

**Пример 2:**
$$y' + 3y = x$$
1.  Однородное решение: $y = Ce^{-3x}$.
2.  Ищем решение в виде $y = C(x)e^{-3x}$.
3.  Подстановка: $C'e^{-3x} \cancel{- 3Ce^{-3x}} \cancel{+ 3Ce^{-3x}} = x \ \Rightarrow \ C' = x e^{3x}$.
4.  Интегрируем по частям:
$$C(x) = \int x e^{3x} dx = \frac{1}{3} \int x \, d(e^{3x}) = \frac{1}{3} \left( x e^{3x} - \frac{1}{3} e^{3x} \right) + K$$
5.  Общее решение:
$$y = \left[ \frac{1}{3} \left( x - \frac{1}{3} \right) e^{3x} + K \right] e^{-3x} = \underbrace{\frac{1}{3} \left( x - \frac{1}{3} \right)}_{\text{частное реш. неодн.}} + \underbrace{K e^{-3x}}_{\text{общее реш. одн.}}$$

**Важное свойство:** Общее решение неоднородного линейного уравнения есть сумма частного решения неоднородного и общего решения однородного.

### Способ 2. Метод подстановки (метод Бернулли)
Ищем решение в виде произведения двух неизвестных функций:
$$y = u(x) \cdot v(x)$$
Подставляем в уравнение:
$$u'v + v'u + p \cdot u \cdot v = q$$
Группируем слагаемые с $u$ и выносим $v$ за скобки:
$$(u' + pu)v + v'u = q$$
Так как мы ввели две функции, на одну из них можно наложить условие. Потребуем, чтобы выражение в первых скобках равнялось нулю:
$$\begin{cases} u' + pu = 0 \\ v'u = q \end{cases}$$
1. Из первого уравнения (однородного) находим $u = \exp(-\int p dx)$ (константа интегрирования не нужна, можно взять любую ненулевую функцию).
2. Подставляем найденное $u$ во второе уравнение и находим $v$:
$$v' = \frac{q}{u} \quad \Rightarrow \quad v = \int \frac{q}{u} dx + C$$
3. Записываем ответ: $y = u \cdot v$.

**Пример 3 (та же задача):**
$$y' + 3y = x$$
1. $y = uv$, подстановка: $u'v + v'u + 3uv = x$.
2. Система:
$$\begin{cases} (u' + 3u)v = 0 \\ v'u = x \end{cases}$$
3. Решаем первое: $u' = -3u \ \Rightarrow \ u = e^{-3x}$.
4. Подставляем во второе: $v'e^{-3x} = x \ \Rightarrow \ v' = xe^{3x} \ \Rightarrow \ v = \frac{1}{3}(x - \frac{1}{3})e^{3x} + C$.
5. Ответ: $y = uv = \frac{1}{3}(x - \frac{1}{3}) + Ce^{-3x}$.

**Пример 4 (поиск частного решения подбором):**
$$xy' + 3y = x^2$$
Сначала решаем однородное уравнение $xy'+3y=0$:
$$x \frac{dy}{dx} = -3y \ \Rightarrow \ \frac{dy}{y} = -\frac{3}{x}dx$$
$$\ln|y| = -3\ln|x| + \ln|C| \ \Rightarrow \ y = Cx^{-3} \quad \text{(общее реш. однор.)}$$
Ищем частное решение неоднородного уравнения в виде степенной функции. Поскольку правая часть $x^2$, предположим $y_{\text{ч.н.}} = ax^n$. Подставляем:
$a \cdot n x^n + 3a x^n = x^2$
Сразу видно, что $n=2$, и получаем $5a = 1 \ \Rightarrow \ a = 1/5$.
Частное решение: $y_{\text{ч.н.}} = \frac{1}{5}x^2$.
Общее решение неоднородного:
$$y = \frac{1}{5}x^2 + Cx^{-3}$$

**Пример 5 (Уравнение, линейное относительно $x$):**
$$y' = \frac{1}{2x - y^2}$$
В этом виде оно не линейно. Но можно перевернуть дробь и рассматривать $x$ как функцию от $y$:
$$\frac{dx}{dy} = 2x - y^2 \ \Rightarrow \ \frac{dx}{dy} - 2x = -y^2$$
Это линейное уравнение относительно $x(y)$. Решаем методом подстановки $x = u(y)v(y)$:
$$u'_y v + u v'_y - 2uv = -y^2 \ \Rightarrow \ (u'_y - 2u)v + u v'_y = -y^2$$
Накладываем условие $u'_y - 2u = 0 \ \Rightarrow \ u = e^{2y}$.
Тогда $u v'_y = -y^2 \ \Rightarrow \ e^{2y} v'_y = -y^2$.
Находим $v$ интегрированием по частям:
$$v = -\int y^2 e^{-2y} dy = \frac{1}{2}e^{-2y}\left( y^2 + y + \frac{1}{2} \right) + C$$
Ответ:
$$x = uv = \frac{1}{2}\left( y^2 + y + \frac{1}{2} \right) + C e^{2y}$$
