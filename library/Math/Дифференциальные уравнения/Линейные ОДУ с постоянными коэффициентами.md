# Линейные ОДУ с постоянными коэффициентами
## Постановка задачи
**Линейный оператор с постоянными коэффициентами:**
$$Lx(t) = x^{(n)} + a_{n-1}x^{(n-1)} + \dots + a_1x' + a_0x, \quad a_k \in \mathbb{R}$$
## Однородное уравнение $Lx = 0$
### Характеристический многочлен
Ищем решение в виде $x(t) = e^{\lambda t}$. Подстановка даёт:
$$(\lambda^n + a_{n-1}\lambda^{n-1} + \dots + a_1\lambda + a_0)e^{\lambda t} = 0$$

**Определение.** $p(\lambda) = \lambda^n + a_{n-1}\lambda^{n-1} + \dots + a_1\lambda + a_0$ — **характеристический многочлен** оператора $L$.
Если $p(\lambda_*) = 0$, то $x_*(t) = e^{\lambda_* t}$ — решение.

Пусть характеристический многочлен разложен на множители:
$$p(\lambda) = (\lambda - \lambda_1)^{k_1} \dots (\lambda - \lambda_m)^{k_m}, \quad k_1 + \dots + k_m = n$$
$\{ e^{\lambda_{j}t} \}^m_{1}$ - решения линейного однородного
### Свойство кратных корней
**Утверждение.** Если $\lambda_*$ — корень кратности $k$, то
$$p(\lambda_*) = p'(\lambda_*) = \dots = p^{(k-1)}(\lambda_*) = 0$$
### Лемма (о решениях для кратного корня)
Пусть $\lambda_*$ — корень характеристического многочлена кратности $k \geq 1$. Тогда функции
$$\varphi_j(t) = t^j \cdot e^{\lambda_* t}, \quad j = 0, 1, \dots, k-1$$
являются решениями однородного уравнения $Lx = 0$.

**Доказательство (база индукции, $k=2$):**
Нужно показать $L(t e^{\lambda_* t}) = 0$.
Вычислим производные:
$(t e^{\lambda_* t})' = e^{\lambda_* t} + \lambda_* t e^{\lambda_* t}$
$(t e^{\lambda_* t})'' = 2\lambda_* e^{\lambda_* t} + \lambda_*^2 t e^{\lambda_* t}$
$\dots$
$(t e^{\lambda_* t})^{(n)} = n\lambda_*^{n-1} e^{\lambda_* t} + \lambda_*^n t e^{\lambda_* t}$
Домножаем на коэффициенты $a_0, a_1, \dots, a_{n-1}, 1$ и суммируем:
$$L(t e^{\lambda_* t}) = t e^{\lambda_* t} p(\lambda_*) + e^{\lambda_* t} p'(\lambda_*) = 0 + 0 = 0$$
(Так как $\lambda_*$ — корень кратности $\geq 2$, то $p(\lambda_*) = p'(\lambda_*) = 0$).
### Следствие (ФСР для случая кратных корней)
Система функций
$$\{ t^j e^{\lambda_p t} \}_{p=1,\dots,m; \ j=0,\dots,k_p-1}$$
образует фундаментальную систему решений однородного уравнения. Количество функций равно $k_1 + \dots + k_m = n$.
### Лемма (о линейной независимости)
Пусть
$$\sum_{j=1}^m P_j(t) e^{\lambda_j t} = 0, \quad t \in [0,T]$$
где $\lambda_j \in \mathbb{C}$ различны, $P_j$ — многочлены. Тогда все $P_j \equiv 0$.

**Доказательство (индукция по $m$):**
**База:** $m = 1$. $P_1(t) e^{\lambda_1 t} = 0 \implies P_1 = 0$. Очевидно.

**Шаг индукции.** Пусть утверждение верно для $m$, докажем для $m+1$.

**Случай 1:** Одно из $\lambda_j = 0$.
Без ограничения общности $\lambda_1 = 0$.
$$P_1(t) + \sum_{j=2}^{m+1} P_j(t) e^{\lambda_j t} = 0$$
Дифференцируем $l$ раз, где $l = \deg P_1 + 1$:
$$\frac{d^l}{dt^l} P_1(t) + \sum_{j=2}^{m+1} \frac{d^l}{dt^l} \left( P_j(t) e^{\lambda_j t} \right) = 0$$
Первое слагаемое зануляется (производная многочлена степени $l-1$ порядка $l$ равна нулю). Во втором слагаемом при дифференцировании экспонента сохраняется, а степень многочлена не меняется:
$$\sum_{j=2}^{m+1} Q_j(t) e^{\lambda_j t} = 0, \quad \deg Q_j = \deg P_j$$
Получили сумму из $m$ слагаемых. По предположению индукции $Q_j = 0$, а значит и $P_j = 0$.

**Случай 2:** Все $\lambda_j \neq 0$, $j = \overline{1, m+1}$.
Умножим тождество на $e^{-\lambda_1 t}$:
$$P_1(t) + \sum_{j=2}^{m+1} P_j(t) e^{(\lambda_j - \lambda_1)t} = 0$$
Продифференцируем $l = \deg P_1 + 1$ раз. Первое слагаемое исчезает. Показатели экспонент $\mu_j = \lambda_j - \lambda_1 \neq 0$ (так как $\lambda_j$ различны). Снова получаем сумму из $m$ слагаемых:
$$\sum_{j=2}^{m+1} R_j(t) e^{\mu_j t} = 0$$
По предположению индукции $R_j = 0 \implies P_j = 0$, а тогда и $P_1 = 0$.

Лемма доказана.
### Теорема (ФСР)
Пусть $p(\lambda) = (\lambda - \lambda_1)^{k_1} \dots (\lambda - \lambda_m)^{k_m}$ — характеристический многочлен $L$. Тогда система
$$\{ t^j \cdot e^{\lambda_p t} \}_{p=\overline{1,m},\ j=\overline{0, k_p-1}}$$
является фундаментальной системой решений однородного уравнения $Lx = 0$.

**Доказательство.**
1.  **Каждая функция — решение.**
    По лемме (о решениях для кратного корня), если $\lambda_p$ — корень кратности $k_p$, то $t^j e^{\lambda_p t}$ при $j = 0, 1, \dots, k_p-1$ является решением уравнения $Lx = 0$.
2.  **Линейная независимость.**
    Предположим противное: пусть существует нетривиальная линейная комбинация, тождественно равная нулю:
    $$\sum_{p=1}^m \left( \sum_{j=0}^{k_p-1} c_{jp} t^j \right) e^{\lambda_p t} = 0, \quad t \in [0,T]$$
    Обозначим $P_p(t) = \sum_{j=0}^{k_p-1} c_{jp} t^j$ — многочлен степени не выше $k_p - 1$. Тогда:
    $$\sum_{p=1}^m P_p(t) e^{\lambda_p t} = 0$$
    Так как $\lambda_1, \dots, \lambda_m$ различны, по лемме о линейной независимости все многочлены $P_p(t) \equiv 0$. Это означает, что все коэффициенты $c_{jp} = 0$ для всех $p, j$.
    Следовательно, система линейно независима.
3.  **Количество функций.**
    Число функций в системе равно $k_1 + k_2 + \dots + k_m = n$, что совпадает с размерностью пространства решений ($\dim X = n$).
Система из $n$ линейно независимых решений является фундаментальной. $\square$
### Пример 1
$$x''' - 9x' = 0$$
Характеристический многочлен: $\lambda^3 - 9\lambda = \lambda(\lambda - 3)(\lambda + 3) = 0$.
Корни: $\lambda = 0, \pm 3$ (все кратности 1).
ФСР: $\{1, e^{3t}, e^{-3t}\}$.
**Ответ:** $x(t) = C_1 + C_2 e^{3t} + C_3 e^{-3t}$.
### Пример 2
$$
\begin{cases}
x'' - 3x' + 2x = 0 \\
x(0) = 0, \ x'(0) = 1
\end{cases}
$$
Характеристическое уравнение: $\lambda^2 - 3\lambda + 2 = 0$.
Корни: $\lambda_1 = 1$, $\lambda_2 = 2$.
Общее решение: $x(t) = C_1 e^t + C_2 e^{2t}$.
Начальные условия:
$x(0) = C_1 + C_2 = 0$
$x'(0) = C_1 + 2C_2 = 1$
$\Rightarrow C_1 = -1, \ C_2 = 1$.
Ответ: $x(t) = e^{2t} - e^t$.

### Пример 3
$$x'' - 2x' + 5x = 0$$
$\lambda^2 - 2\lambda + 5 = 0$.
$\lambda_{1,2} = 1 \pm 2i$.
Общее решение (используем $e^{i\alpha} = \cos \alpha + i \sin \alpha$):
$$x(t) = e^t \left( C_1 \cos 2t + C_2 \sin 2t \right)$$

### Пример 4
$$x^{(4)} + 4x = 0$$
$\lambda^4 + 4 = 0 \ \Rightarrow \ \lambda^2 = \pm 2i$.

Решаем $\lambda^2 = 2i$. Пусть $\lambda = a + ib$:
$a^2 - b^2 + 2abi = 2i$
$$
\begin{cases}
a^2 - b^2 = 0 \\
ab = 1
\end{cases}
\ \Rightarrow \ a = \pm b, \ \pm a^2 = 1 \ \Rightarrow \ a=1, \ b=1
$$
Корни: $\lambda = 1 \pm i$, $\lambda = -1 \pm i$.
ФСР: $\{ e^t \cos t, e^t \sin t, e^{-t} \cos t, e^{-t} \sin t \}$.
Общее решение:
$$x(t) = e^t (C_1 \cos t + C_2 \sin t) + e^{-t} (C_3 \cos t + C_4 \sin t)$$

### Пример 5
$$x''' - 3x'' + 3x' - x = 0$$
$\lambda^3 - 3\lambda^2 + 3\lambda - 1 = 0 \ \Rightarrow \ (\lambda - 1)^3 = 0$.
Корень $\lambda = 1$, кратность $k = 3$.
ФСР: $\{ e^t, t e^t, t^2 e^t \}$.
Общее решение:
$$x(t) = e^t \left( C_1 + C_2 t + C_3 t^2 \right)$$

### Пример 6
$$x''' - x = 0$$
$\lambda^3 - 1 = 0 \ \Rightarrow \ (\lambda - 1)(\lambda^2 + \lambda + 1) = 0$.
Корни: $\lambda_1 = 1$, $\lambda_{2,3} = \frac{-1 \pm \sqrt{3}i}{2}$.
ФСР: $\left\{ e^t, e^{-t/2} \cos \frac{\sqrt{3}}{2}t, e^{-t/2} \sin \frac{\sqrt{3}}{2}t \right\}$.

### Пример 7
$$x^{(4)} + 2x'' + x = 0$$
$\lambda^4 + 2\lambda^2 + 1 = 0 \ \Rightarrow \ (\lambda^2 + 1)^2 = 0 \ \Rightarrow \ (\lambda - i)^2 (\lambda + i)^2 = 0$.
Корни: $\lambda = \pm i$, кратность $k = 2$.
ФСР: $\{ e^{it}, t e^{it}, e^{-it}, t e^{-it} \}$.
Общее решение:
$$x(t) = (C_1 + C_3 t) \cos t + (C_2 + C_4 t) \sin t$$
