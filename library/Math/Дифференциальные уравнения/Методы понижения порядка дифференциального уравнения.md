# Методы понижения порядка дифференциального уравнения
## Метод 1: Уравнение не содержит младших производных
Вид: $F(t, x^{(k)}, x^{(k+1)}, \dots, x^{(n)}) = 0$.
Замена: $z = x^{(k)}$. Получаем уравнение $(n-k)$-го порядка:
$$F(t, z, z', \dots, z^{(n-k)}) = 0$$

## Метод 2: Уравнение не содержит независимую переменную $t$
Вид: $F(x, x', \dots, x^{(n)}) = 0$.
Замена: $z = x'$, тогда $x$ — новая независимая переменная.
Производные выражаются через $z$:
$x'' = z_x \cdot z$
$x''' = (z_x \cdot z)_x = z_{xx} \cdot z^2 + z_x^2 \cdot z$
$\dots$
Порядок понижается на единицу.
*Замечание:* Если $F(a, 0, \dots, 0) = 0$, то $x(t) = a$ — решение.

**Пример:**
$$(1 + x^2)x \cdot x'' = (3x^2 - 1)(x')^2$$
Замена $z = x'$, $x'' = z_x \cdot z$:
$$(1 + x^2)x \cdot z_x z = (3x^2 - 1)z^2$$
1.  **Случай $z = 0$:** $x = C = \text{const}$.
2.  **Случай $z \neq 0$:** Сокращаем $z$ и разделяем переменные:
    $$(1 + x^2)x \, z_x = (3x^2 - 1)z \ \Rightarrow \ \frac{dz}{z} = \frac{3x^2 - 1}{(1 + x^2)x} dx$$
    Раскладываем дробь: $\frac{3x^2 - 1}{(x^2+1)x} = \frac{4x}{x^2+1} - \frac{1}{x}$.
    Интегрируем:
    $$\int \frac{dz}{z} = \int \left( \frac{4x}{x^2+1} - \frac{1}{x} \right) dx$$
    $$\ln|z| = 2\ln|x^2+1| - \ln|x| + \ln|C_1| \ \Rightarrow \ z = \frac{C_1 (x^2+1)^2}{x}$$
    Возвращаемся к $x$: $x' = z = \frac{C_1 (x^2+1)^2}{x}$.
    Разделяем переменные и интегрируем:
    $$\frac{x \, dx}{(x^2+1)^2} = C_1 dt \ \Rightarrow \ \frac{1}{2} \int \frac{d(x^2)}{(x^2+1)^2} = \int C_1 dt$$
    $$-\frac{1}{2(x^2+1)} = C_1 t + C_2$$

## Метод 3: Однородные уравнения относительно $x, x', \dots$
Уравнение $F(t, x, x', \dots, x^{(n)}) = 0$ называется **однородным** степени $m$ относительно $x$ и производных, если:
$$F(t, \lambda x, \lambda x', \dots, \lambda x^{(n)}) = \lambda^m F(t, x, x', \dots, x^{(n)})$$
Замена: $x' = z \cdot x$.
Тогда:
$x'' = z'x + z^2 x = x(z' + z^2)$
$x''' = x(z'' + 3zz' + z^3)$
$\dots$
Выносим $x^m$: $F(t, x, x', \dots, x^{(n)}) = x^m F(t, 1, z, z'+z^2, \dots) = 0$.
Получаем уравнение $(n-1)$-го порядка относительно $z$.

**Пример:**
$$t x x'' - t (x')^2 - x x' = 0$$
Уравнение однородно степени $m=2$.
Замена $x' = zx$, $x'' = x(z' + z^2)$:
$$t x^2(z' + z^2) - t z^2 x^2 - x^2 z = 0$$
Сокращаем $x^2 \neq 0$:
$$t(z' + z^2) - t z^2 - z = 0 \ \Rightarrow \ t z' = z$$
Разделяем переменные:
$$\frac{dz}{z} = \frac{dt}{t} \ \Rightarrow \ z = C_1 t$$
Возвращаемся к $x$: $x' = C_1 t x \ \Rightarrow \ \frac{dx}{x} = C_1 t \, dt \ \Rightarrow \ x = C_2 e^{C_1 t^2 / 2}$
Или:
$$
x = C_{2} e^{C_{1} t^{2}}
$$

## Метод 4: Уравнение в точных производных
Если удаётся представить левую часть как полную производную некоторой функции $\Phi$:
$$F(t, x, x', \dots, x^{(n)}) = \frac{d}{dt} \Phi(t, x, x', \dots, x^{(n-1)})$$
То, интегрируя, получаем уравнение $(n-1)$-го порядка:
$$\Phi(t, x, x', \dots, x^{(n-1)}) = C_1 = \text{Const}$$

**Пример:**
$$
\begin{cases}
x'' = tx' + x + 1 \\
x(0) = 1 \\
x'(0) = 0
\end{cases}
$$
Замечаем, что правая часть сворачивается: $tx' + x + 1 = (tx + t)'$.
Тогда $x'' = (tx + t)'$. Интегрируем:
$$x' = tx + t + C_1$$
Из начальных условий: $x'(0) = 0 \cdot 1 + 0 + C_1 = 0 \ \Rightarrow \ C_1 = 0$.
Решаем уравнение $x' = t(x+1)$ (разделяем переменные):
$$\frac{dx}{x+1} = t \, dt \ \Rightarrow \ \ln|x+1| = \frac{t^2}{2} + \ln|C_2| \ \Rightarrow \ x+1 = C_2 e^{t^2/2}$$
Из начального условия $x(0) = 1$ получаем $2 = C_2$.
Ответ: $x(t) = 2 e^{t^2/2} - 1$.
