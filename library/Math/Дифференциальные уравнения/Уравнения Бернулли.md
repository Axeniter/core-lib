# Уравнения Бернулли
**Общий вид:**
$$y' + p(x)y = q(x)y^n, \quad n \neq 0, \ 1$$

## Способ 1: Сведение к линейному уравнению
Разделим обе части на $y^n$:
$$y^{-n} y' + p y^{1-n} = q$$
Вводится замена $z = y^{1-n}$. Тогда $z' = (1-n)y^{-n}y'$.
Уравнение становится линейным:
$$\frac{1}{1-n}z' + p(x)z = q(x) \ \Rightarrow \ z' + (1-n)p(x)z = (1-n)q(x)$$

## Способ 2: Метод подстановки $y = uv$
Подставляем $y = uv$ в исходное уравнение:
$$u'v + uv' + puv = q u^n v^n$$
Накладываем на $u$ условие $u' + pu = 0$. Находим $u = \exp(-\int p dx)$.
Тогда $u'$ и $pu$ сокращаются, и остается:
$$uv' = q u^n v^n$$
Делим на $u$:
$$v' = q u^{n-1} v^n$$
Это уравнение с разделяющимися переменными относительно $v$. Обозначив $q_1 = q u^{n-1}$, получим:
$$\frac{dv}{dx} = q_1 v^n$$

**Пример:**
$$y' = \frac{4}{x}y + x \sqrt{y}$$
Это уравнение Бернулли ($n = 1/2$). Решаем подстановкой $y = uv$.
$$u'v + uv' = \frac{4}{x}uv + x\sqrt{uv}$$
Переносим слагаемые, чтобы выделить условие для $u$:
$$u'v + u\left(v' - \frac{4}{x}v\right) = x\sqrt{uv}$$
Удобнее сразу записать систему:
1. Из слагаемых с $v$ (без производной) при $u$: $u' = \frac{4}{x}u \ \Rightarrow \ u = x^4$.
2. Подставляем $u$ в оставшуюся часть:
    $$v' x^4 = x \sqrt{x^4 v}$$
    При $x > 0$: $v' x^4 = x \cdot x^2 \sqrt{v} \ \Rightarrow \ v' = \frac{1}{x} \sqrt{v}$.
3. Разделяем переменные:
$$\frac{dv}{\sqrt{v}} = \frac{dx}{x} \ \Rightarrow \ 2\sqrt{v} = \ln x + C \ \Rightarrow \ v = \frac{1}{4}(\ln x + C)^2$$
4. Ответ:
$$y = uv = \frac{1}{4} x^4 (\ln x + C)^2$$
