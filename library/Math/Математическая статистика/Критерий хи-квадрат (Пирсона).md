# Критерий χ² (хи-квадрат)
## Критерий χ² для таблиц сопряжённости 2×2
Предположим, что признак имеет только два взаимоисключающих значения (например, «сделано» / «не сделано»). Тогда результаты измерения для двух групп (экспериментальной и контрольной) можно представить в виде четырёхпольной таблицы 2×2:

| Группа           | I категория | II категория | Всего |
| ---------------- | ----------- | ------------ | ----- |
| Экспериментальная | $Э_1$       | $Э_2$        | $n_Э$ |
| Контрольная      | $К_1$       | $К_2$        | $n_К$ |
| **Всего**        | $Э_1+К_1$   | $Э_2+К_2$    | $N$   |
где:
- $n_Э = Э_1 + Э_2$ — объём экспериментальной группы,
- $n_К = К_1 + К_2$ — объём контрольной группы,
- $N = n_Э + n_К$ — общий объём.
На основе данных таблицы можно проверить гипотезу о равенстве вероятностей попадания объектов экспериментальной и контрольной групп в I или II категорию.

### Расчётное значение критерия χ²
$$\chi^2_{\text{расч}} = \frac{N (Э_1 К_2 - Э_2 К_1)^2}{n_Э n_К (Э_1 + К_1)(Э_2 + К_2)}$$
По таблице критических точек распределения $\chi^2$ с числом степеней свободы $k = 1$ и заданным уровнем значимости $\alpha$ находим $\chi^2_{\text{табл}}$.

### Принятие решения
- Если $\chi^2_{\text{расч}} > \chi^2_{\text{табл}}$ — разница результатов **не случайна**, одна из методик лучше (нулевая гипотеза об отсутствии различий отвергается).
- Если $\chi^2_{\text{расч}} \leq \chi^2_{\text{табл}}$ — разница статистически незначима.

### Замечания по применению критерия
1. Критерий $\chi^2$ **не рекомендуется** использовать, если:
   - $n < 20$,
   - или $\min(Э_1, Э_2, К_1, К_2) < 5$.
2. **Поправка Йейтса на непрерывность.** Если хотя бы одна из величин $Э_1, Э_2, К_1, К_2$ находится в интервале $[5; 10]$, то применяется формула с поправкой:
   $$\chi^2_{\text{расч}} = \frac{N \left(|Э_1 К_2 - Э_2 К_1| - \frac{N}{2}\right)^2}{n_Э n_К (Э_1 + К_1)(Э_2 + К_2)}$$

## Критерий χ² для таблиц с более чем двумя категориями
Если результаты измерения признака имеют **более двух категорий**, данные записываются в виде таблицы:

| Группа       | $I_k$ | $II_k$ | $\dots$ | $p$-я категория | Всего |
| ------------ | ----- | ------ | ------- | --------------- | ----- |
| Эксп.        | $Э_1$ | $Э_2$  | $\dots$ | $Э_p$           | $n_Э$ |
| Контр.       | $К_1$ | $К_2$  | $\dots$ | $К_p$           | $n_К$ |
где:
- $n_Э = \sum_{i=1}^{p} Э_i$
- $n_К = \sum_{i=1}^{p} К_i$

### Расчётное значение критерия χ²
$$\chi^2_{\text{расч}} = \frac{1}{n_Э n_К} \sum_{i=1}^{p} \frac{(n_Э К_i - n_К Э_i)^2}{Э_i + К_i}$$

### Табличное значение
$\chi^2_{\text{табл}}$ находится по таблице критических точек распределения $\chi^2$ с числом степеней свободы $k = p - 1$ и заданным уровнем значимости $\alpha$.
