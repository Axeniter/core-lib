# Выборочный метод
## Генеральная и выборочная совокупности
Часть объектов исследования, определенным образом выбранная из более обширной совокупности, называется **выборкой**. Исходная совокупность, из которой взята выборка, называется **генеральной совокупностью**.

**Объемом совокупности** (генеральной или выборочной) называют число объектов в совокупности.

Все объекты, составляющие генеральную совокупность, должны иметь хотя бы один общий признак.

Таким образом, статистическая совокупность представляет собой результаты описания или измерения общих признаков объектов исследования.

## Повторная и бесповторная выборка. 
В **бесповторной** выборке элемент не возвращается в совокупность. В **повторной** — возвращается.

## Репрезентативная выборка
**Репрезентативная выборка** — выборка, правильно представляющая пропорции генеральной совокупности. Выборка является репрезентативной, если все элементы выбираются случайно с равными вероятностями.

## Способы отбора
1. Отбор, не требующий расчленения генеральной совокупности на части:
	- Простой случайный бесповторный отбор.
	- Простой случайный повторный отбор.
2. Отбор, при котором генеральная совокупность разбивается на части:
	- Типический
	- Механический
	- Серийный

**Простой случайный отбор** — отбор, при котором объекты выбираются по одному из генеральной совокупности.

**Типический отбор** — отбор, при котором объекты выбираются не из генеральной совокупности, а из каждой её типической части. Используют, когда исследуемый признак заметно колеблется в зависимости от типической части совокупности.

**Механический отбор** — отбор, при котором генеральную совокупность механически делят на столько групп, сколько объектов должно войти в выборку, а из каждой группы выбирают один объект.

**Серийный отбор** — отбор, при котором объекты выбирают из совокупности не по одному, а сериями, которые подвергаются сплошному обследованию. Используют, когда исследуемый признак колеблется в незначительных сериях.
