# Формы зависимостей
## Формы взаимосвязей
1. **Функциональная связь:** $y = f(x)$ — каждому значению $x$ соответствует строго одно значение $y$.
2. **Корреляционная (статистическая) связь:** $\bar{y} = f(x)$ — одному значению показателя соответствует несколько значений другого показателя, но его среднее значение (или другая статистическая характеристика) изменяется по определённому закону.
   **Корреляционная связь** — частный случай статистической: $\bar{y} = f(x)$ означает, что среднее значение одного показателя изменяется в зависимости от другого.

## Классификация корреляционных связей
- **По аналитическому виду функции:** линейные и нелинейные.
- **По направлению:**
  - прямые (положительные) — переменная растёт с увеличением факторного признака,
  - обратные (отрицательные) — переменная убывает с увеличением факторного признака.
- **По силе:** слабые и сильные.
