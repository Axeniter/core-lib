# Теорема Гаусса-Маркова и свойства оценок МНК
## Модель наблюдений
Свойства оценок МНК определяется предположениями относительно свойств случайного допущения модели наблюдений. Эти предположения называются условиями Гаусса-Маркова.

Рассматривается модель зависимости $Y$ от $X$:
$$Y_i = \beta_1 + \beta_2 X_i + \varepsilon_i$$

Детерминированная часть:
$$Y_i = \beta_1 + \beta_2 X_i$$
где $\varepsilon_i$ — случайная ошибка (возмущение).

## Теорема Гаусса-Маркова
Если данные обладают следующими свойствами:
1. **Модель данных правильно специфицирована.**
2. Все $x_i$ **детерминированы** и не все равны между собой.
3. Ошибки **не носят систематического характера**: $E(\varepsilon_i) = 0$ для всех $i$.
4. **Дисперсия ошибок одинакова** (гомоскедастичность): $E(\varepsilon_i^2) = \sigma^2 = \text{const}$.
5. Ошибки **не коррелированы**: $\text{cov}(\varepsilon_i, \varepsilon_j) = 0$ для всех $i \neq j$,

то оценки метода наименьших квадратов **оптимальны в классе линейных несмещённых оценок** (являются BLUE — Best Linear Unbiased Estimators).

## Предпосылки классической регрессионной модели (МНК)
1. **Линейность модели:**
   $$y = a + bx + \varepsilon$$
   где $\varepsilon$ — случайная ошибка. Модель линейна по параметрам $a$ и $b$. Оценка проводится по МНК (минимизация суммы квадратов отклонений).

2. **Спецификация модели:**
   При отсутствии систематической составляющей (все $x_i = 0$) зависимая переменная $y_i$ определяется только случайным членом. Если в модель не включены значимые факторы, она сможет объяснить лишь малую часть вариации $y$.

3. **Случайный член $\varepsilon$ — случайная величина.** Он не должен иметь систематического смещения ни в одну из сторон.

4. **Нулевое математическое ожидание случайного члена:**
   $$E(\varepsilon_i) = 0 \quad \text{для всех } i$$

5. **Гомоскедастичность (постоянство дисперсии):**
   $$E(\varepsilon_i^2) = \sigma^2 = \text{const} \quad \text{для всех } i$$

6. **Отсутствие автокорреляции случайного члена:**
   $$E(\varepsilon_i \varepsilon_j) = 0 \quad \text{для } i \neq j$$

## Свойства оценок МНК
1. **Состоятельность:** оценка с увеличением объёма выборки приближается к истинному значению параметра.

2. **Эффективность:** оценка имеет наименьшую дисперсию среди всех несмещённых оценок.

3. **Несмещённость:** математическое ожидание оценки равно истинному значению параметра.
