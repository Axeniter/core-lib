# Ранговые коэффициенты корреляции
Применяются, когда значения признака можно **упорядочить (ранжировать)** по убыванию или возрастанию.

### Коэффициент корреляции Спирмена ($\rho_{xy}$)
**Алгоритм расчёта:**
1. Значения каждого признака ранжируют (присваивают порядковый номер).
2. Записывают $X$ и $Y$ с указанием рангов.
3. Для каждой пары вычисляют разность рангов: $d_i = R_{x_i} - R_{y_i}$.
**Формула:**
$$\rho_{xy} = 1 - \frac{6 \sum_{i=1}^{n} d_i^2}{n(n^2 - 1)}$$
где $n$ — объём выборки.
**Свойства:**
- Изменяется от $-1$ до $1$.

### Проверка значимости коэффициента Спирмена
Используется критерий Стьюдента.
**Гипотезы:**
- $H_0: \rho_{xy} = 0$ (корреляция отсутствует)
- $H_1: \rho_{xy} \neq 0$
**Расчётное значение:**
$$t_{\text{расч}} = |\rho_{xy}| \cdot \sqrt{\frac{n - 2}{1 - \rho_{xy}^2}}$$
**Табличное значение:** $t_{\text{табл}}$ для $\alpha = 0.05$ и $k = n - 2$.
**Принятие решения:**
- Если $t_{\text{расч}} > t_{\text{табл}}$ — $H_0$ **отвергается**, $\rho_{xy}$ статистически значим.
- Иначе — $H_0$ принимается.

### Коэффициент конкордации (множественный ранговый коэффициент)
Применяется для определения тесноты связи между **произвольным числом признаков**.
**Формула:**
$$W = \frac{12 S}{m^2 (n^3 - n)}$$
где:
- $n$ — объём выборки (число наблюдений),
- $m$ — число факторов (признаков),
- $S$ — отклонение квадратичной суммы рангов от средней квадратичной суммы:
$$S = R_x^2 + R_y^2 + R_z^2 - \frac{(R_x + R_y + R_z)^2}{3}$$
где $R_x$, $R_y$, $R_z$ — суммы рангов по каждому фактору.

### Проверка значимости коэффициента конкордации
Используется критерий $\chi^2$ (Пирсона).
**Расчётное значение:**
$$\chi^2_{\text{расч}} = \frac{12 S}{m n (n - 1)}$$
**Табличное значение:** $\chi^2_{\text{табл}}$ для заданного $\alpha$ и $k = n - 1$.
**Принятие решения:**
- Если $\chi^2_{\text{расч}} > \chi^2_{\text{табл}}$ — $W$ статистически значим.
- Иначе — $W$ незначим.
