# Проверка статистических гипотез
## Основные понятия
**Статистической гипотезой** называют проверяемое математическими методами предположение относительно статистических характеристик результатов измерения.

Рассматривают две совокупности. При сравнении соответствующих статистических характеристик практически никогда не встречается их абсолютное равенство. Это различие может быть обусловлено либо **случайностью**, либо **закономерностью**.

**Задача проверки гипотез** — отличить случайные явления от закономерных.

## Нулевая и альтернативная гипотезы
- **$H_0$** (нулевая гипотеза): между двумя совокупностями нет ожидаемого различия.
- **$H_1$** (конкурирующая, альтернативная гипотеза): между двумя совокупностями есть различия.
Примеры формулировок:
- $H_0: \bar{X}_1 = \bar{X}_2$
- $H_1: \bar{X}_1 \neq \bar{X}_2$ или $\bar{X}_1 > \bar{X}_2$

## Ошибки при проверке гипотез
Так как проверка гипотез осуществляется по выборочным значениям, всегда существует риск принять неправильное решение.

| Тип ошибки | Суть | Вероятность |
|-----------|------|-------------|
| **Ошибка I рода** | Отвергнута правильная нулевая гипотеза | $\alpha$ — уровень значимости |
| **Ошибка II рода** | Принята неправильная нулевая гипотеза | $\beta$ |

## Статистический критерий
**Статистическим критерием** называют случайную величину $K$, которая служит для проверки гипотезы.

**Наблюдаемым (эмпирическим) значением** называют то значение критерия, которое вычислено по выборкам.

## Критическая область и область принятия гипотезы
- **Критическая область** — совокупность значений критерия, при которой гипотезу $H_0$ отвергают.
- **Область принятия гипотезы** — совокупность значений критерия, при которой гипотезу $H_0$ принимают.
- **Критические точки (границы)** — точки, отделяющие критическую область от области принятия гипотезы.

### Виды критических областей
1. **Правосторонняя:** определяется неравенством $K > K_{\text{кр}}$.
2. **Левосторонняя:** определяется неравенством $K < K_{\text{кр}}$.
3. **Двусторонняя:** $K > K_1$, $K < K_2$, где $K_2 > K_1$.

### Отыскание критических точек
Для отыскания критической области задаются уровнем значимости $\alpha$ и ищут критические точки:
- **а) Для правосторонней области:** $P(K > K_{\text{кр}}) = \alpha$, $(K_{\text{кр}} > 0)$
- **б) Для левосторонней области:** $P(K < K_{\text{кр}}) = \alpha$, $(K_{\text{кр}} < 0)$
- **в) Для двусторонней области:** $P(K > K_{\text{кр}}) = \frac{\alpha}{2}$, $K_{\text{кр}} > 0$; $P(K < -K_{\text{кр}}) = \frac{\alpha}{2}$
