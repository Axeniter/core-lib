# Метод моментов
## Суть метода
Метод моментов точечной оценки неизвестных параметров заданного распределения состоит в **приравнивании теоретических моментов соответствующим эмпирическим моментам того же порядка**.

## Случай одного параметра
Если распределение определяется **одним параметром**, то для его отыскания приравнивают один теоретический момент одному эмпирическому моменту того же порядка. Например, приравняем начальный теоретический момент первого порядка начальному эмпирическому моменту первого порядка:
$$v_1 = M_1$$
Учитывая, что $v_1 = M(X)$ и $M_1 = \bar{x}_B$, получим:
$$M(X) = \bar{x}_B \tag{*}$$
Математическое ожидание $M(X)$ является функцией от неизвестного параметра заданного распределения. Решив уравнение $(*)$ относительно неизвестного параметра, получим его точечную оценку.

## Случай двух параметров
Если распределение определяется **двумя параметрами**, то приравнивают два теоретических момента двум соответствующим эмпирическим моментам того же порядка. Например:
$$v_1 = M_1, \quad \mu_2 = m_2$$
Учитывая, что $v_1 = M(X)$, $M_1 = \bar{x}_B$, $\mu_2 = D(X)$, $m_2 = D_B$, имеем систему:
$$\begin{cases}
M(X) = \bar{x}_B, \\
D(X) = D_B.
\end{cases} \tag{**}$$
Левые части этих равенств являются функциями от неизвестных параметров. Решив систему $(**)$ относительно неизвестных параметров, получим их точечные оценки.
**Замечание:** для вычисления $\bar{x}_B$ и $D_B$ необходимо располагать выборкой $x_1, x_2, \dots, x_n$.

## Пример (распределение Пуассона)
**Условие.** Случайная величина $X$ распределена по закону Пуассона:
$$P_m(x_i) = \frac{\lambda^{x_i} e^{-\lambda}}{x_i!}$$
где $x_i$ — число появлений события в $i$-м опыте. Найти методом моментов по выборке $x_1, x_2, \dots, x_n$ точечную оценку неизвестного параметра $\lambda$.
**Решение.**
Требуется оценить **один параметр** → достаточно одного уравнения. Приравняем начальный теоретический момент первого порядка начальному эмпирическому моменту первого порядка:
$$v_1 = M_1$$
Так как $v_1 = M(X)$ и $M_1 = \bar{x}_B$, получаем:
$$M(X) = \bar{x}_B$$
Математическое ожидание распределения Пуассона равно параметру $\lambda$, поэтому:
$$\lambda = \bar{x}_B$$
**Ответ:** точечной оценкой параметра $\lambda$ служит выборочная средняя: $\lambda^* = \bar{x}_B$.
