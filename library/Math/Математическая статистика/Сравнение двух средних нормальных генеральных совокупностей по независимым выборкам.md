# Сравнение двух средних нормальных генеральных совокупностей по независимым выборкам
Пусть генеральные совокупности $X$ и $Y$ распределены нормально, их генеральные дисперсии неизвестны, но предполагается, что они равны. Требуется при заданном уровне значимости $\alpha$ проверить гипотезу о равенстве средних.
## Алгоритм проверки (t-критерий Стьюдента)
1. **Формулировка гипотез:**
   - $H_0: a_X = a_Y$
   - $H_1: a_X \neq a_Y$ (или $a_X > a_Y$)
2. Из $X$ и $Y$ получаем выборки объёмами $n_1$, $n_2$. Вычисляем $\bar{x}$, $\bar{y}$, $S_X^2$, $S_Y^2$.
3. **Расчётное значение критерия (общий случай, $n_1 \neq n_2$):**
   $$t_{\text{расч}} = \frac{|\bar{x} - \bar{y}|}{\sqrt{(n_1 - 1)S_X^2 + (n_2 - 1)S_Y^2}} \cdot \sqrt{\frac{n_1 n_2 (n_1 + n_2 - 2)}{n_1 + n_2}}$$
   **Частный случай ($n_1 = n_2 = n$):**
   $$t_{\text{расч}} = \frac{|\bar{x} - \bar{y}| \sqrt{n}}{\sqrt{S_X^2 + S_Y^2}}$$
4. Число степеней свободы: $k = n_1 + n_2 - 2$.
   **Уровень значимости:**
   - Если $H_1: a_X \neq a_Y$ — берём $\frac{\alpha}{2}$.
   - Если $H_1: a_X > a_Y$ — берём $\alpha$.
   По таблице находим $t_{\text{табл}}$.
5. **Принятие решения:**
   - Если $t_{\text{расч}} < t_{\text{табл}}$ — $H_0$ **принимается**. Различие между выборочными средними объясняется случайными причинами.
   - Если $t_{\text{расч}} \geq t_{\text{табл}}$ — $H_0$ **отвергается**. Средние генеральных совокупностей различны.

### Пример
**Исходные данные:**

| № | Контр. гр. $x_i$ | Эксп. гр. $y_i$ |
|---|-----------------|-----------------|
| 1 | 9.9 | 9.4 |
| 2 | 9.7 | 9.6 |
| 3 | 9.8 | 9.3 |
| 4 | 10.3 | 9.1 |
| 5 | 9.2 | 8.6 |
| 6 | 9.0 | 9.0 |
| 7 | 10.5 | 8.1 |
| 8 | 10.1 | 9.6 |
| 9 | 8.8 | 8.8 |
| 10 | 9.5 | 9.3 |
| 11 | 10.9 | 10.3 |
| 12 | 9.8 | 9.9 |
| **Итого** | **117.5** | **111.0** |
**Шаг 1. Вычисление выборочных средних:**
$$\bar{x} = \frac{117.5}{12} = 9.8$$
$$\bar{y} = \frac{111.0}{12} = 9.3$$
**Шаг 2. Вычисление исправленных дисперсий:**
$$S_X^2 = \frac{4.15}{11} = 0.38$$
$$S_Y^2 = \frac{3.86}{11} = 0.35$$
**Шаг 3. Проверка равенства дисперсий (F-критерий):**
$H_0: \sigma_X^2 = \sigma_Y^2$, $H_1: \sigma_X^2 \neq \sigma_Y^2$, $\alpha = 0.05$
$k_1 = 11$, $k_2 = 11$
$F_{\text{табл}} = 2.82$ (для $\frac{\alpha}{2}$)
$$F_{\text{расч}} = \frac{0.38}{0.35} = 1.09$$
$F_{\text{расч}} < F_{\text{табл}}$ — **различие дисперсий незначимо**.
**Шаг 4. Проверка равенства средних (t-критерий):**
$H_0: a_X = a_Y$, $H_1: a_X \neq a_Y$
$n = 12$
$$t_{\text{расч}} = \frac{(9.8 - 9.3) \sqrt{12}}{\sqrt{0.38 + 0.35}} = 2.03$$
$k = 22$, $\alpha = 0.05$
$t_{\text{табл}} = 2.2$
$t_{\text{расч}} < t_{\text{табл}}$ — **$H_0$ принимается**.
**Вывод:** различие между контрольной и экспериментальной группами статистически незначимо.
