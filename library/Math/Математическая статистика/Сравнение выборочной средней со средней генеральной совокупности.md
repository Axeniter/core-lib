# Сравнение выборочной средней со средней генеральной совокупности
Пусть генеральная совокупность имеет нормальное распределение. Генеральная средняя $a$ неизвестна, но есть основание предполагать, что она равна $a_0$. Требуется по выборке проверить правильность утверждения.

## Алгоритм проверки (t-критерий Стьюдента)
1. **Формулировка гипотез:**
   - $H_0: a = a_0$ (нулевая гипотеза)
   - $H_1: a \neq a_0$ (альтернативная гипотеза)
2. Из генеральной совокупности извлекаем выборку объёма $n$ и по ней находим:
   - выборочную среднюю $\bar{x}$,
   - исправленную выборочную дисперсию:
     $$S^2 = \frac{\sum (x_i - \bar{x})^2}{n - 1}$$
3. **Расчётное значение критерия:**
   $$t_{\text{расч}} = \frac{|\bar{x} - a_0| \sqrt{n}}{S}$$
4. Выбирается **уровень значимости** $\alpha$ (обычно $0.01$ или $0.05$). По таблицам критических точек критерия Стьюдента для **двусторонней критической области** с числом степеней свободы $k = n - 1$ находится $t_{\text{табл}}$.
5. **Принятие решения:**
   - Если $t_{\text{расч}} \geq t_{\text{табл}}$ — гипотеза $H_0$ **отвергается**. Наблюдаемое различие между $\bar{x}$ и $a_0$ нельзя считать случайным.
   - Если $t_{\text{расч}} < t_{\text{табл}}$ — гипотеза $H_0$ **принимается**. Наблюдаемое различие объясняется случайностью выборки.

## Замечание (если известна генеральная дисперсия)
Если дисперсия генеральной совокупности $\sigma^2$ известна, вместо критерия Стьюдента используют **критерий нормального распределения**:
$$Z_{\text{расч}} = \frac{|\bar{x} - a_0| \sqrt{n}}{\sigma}$$
$Z_{\text{табл}}$ берётся из функции Лапласа из условия:
$$\Phi(Z_{\text{табл}}) = \frac{1 - \alpha}{2}$$

## Пример
**Дано:** $n = 20$, $\bar{x} = 16$, $S = 4.5$, $\alpha = 0.05$
**Гипотезы:**
- $H_0: a = a_0 = 15$
- $H_1: a \neq 15$
**Решение:**
$$t_{\text{расч}} = \frac{|\bar{x} - a_0| \sqrt{n}}{S} = \frac{|16 - 15| \sqrt{20}}{4.5} = 0.99$$
$k = 20 - 1 = 19$, $\alpha = 0.05$
$t_{\text{табл}} = 2.09$
Так как $t_{\text{расч}} < t_{\text{табл}}$, **$H_0$ принимается**.
**Вывод:** выборочное среднее незначительно отличается от генеральной средней.
