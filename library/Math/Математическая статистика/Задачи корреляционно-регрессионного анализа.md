# Задачи корреляционно-регрессионного анализа
В общем виде задача статистики в области изучения взаимосвязей состоит в количественной оценке их наличия и направления, а также характеристики силы и формы влияния одних факторов на другие.
Для решения используют **две группы методов**:

| Метод | Задача |
|-------|--------|
| **Корреляционный анализ** | Измерение тесноты связи между варьирующими признаками, определение неизвестных причинных связей и оценка факторов, оказывающих наибольшее влияние на результативный признак. |
| **Регрессионный анализ** | Определение функции регрессии, установление формы зависимости и использование уравнения для оценки неизвестных значений зависимой переменной. |
