# Сравнение двух средних нормальных генеральных совокупностей по связным выборкам
Рассматриваются выборки одинакового объёма, варианты которых попарно зависимы (связные выборки).

Предполагается, что генеральные совокупности $X$ и $Y$ распределены нормально, их дисперсии неизвестны. Необходимо проверить гипотезу о равенстве генеральных средних.

**Идея метода:** задача сравнения двух средних сводится к задаче сравнения одной средней совокупности $D = X - Y$ со значением, равным $0$.

## Алгоритм проверки гипотезы
1. **Формулировка гипотез:**
   - $H_0: a_d = 0$ (нулевая гипотеза)
   - $H_1: a_d \neq 0$ (альтернативная гипотеза)

2. Для каждой пары значений $x_i$ и $y_i$ вычисляем разности:
   $$d_i = x_i - y_i$$

   По полученным разностям находим:
   - выборочную среднюю разностей $\bar{d}$,
   - исправленную выборочную дисперсию разностей $S_d^2$.

3. **Расчётное значение критерия (t-критерий Стьюдента):**
   $$t_{\text{расч}} = \frac{|\bar{d}| \sqrt{n}}{S_d}$$

4. Выбираем уровень значимости $\alpha$, число степеней свободы $k = n - 1$. По таблице критических точек критерия Стьюдента для **двусторонней критической области** находим $t_{\text{табл}}$.

5. **Принятие решения:**
   - Если $t_{\text{расч}} < t_{\text{табл}}$ — $H_0$ **принимается**. Различие средних статистически незначимо.
   - Если $t_{\text{расч}} \geq t_{\text{табл}}$ — $H_0$ **отвергается**. Различие средних статистически значимо.
