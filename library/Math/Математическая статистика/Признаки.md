# Признаки
Предметом изучения статистики являются изменяющиеся, варьирующиеся признаки, которые называются **статистическими**. Признаки различаются способами их измерения.

## Качественные признаки
Качественные признаки — описательные признаки, которые выражаются словесно (например, квалификация). Их измерение проводят по шкале наименований или порядка. Над результатами данных измерений арифметические действия выполнять нельзя.

## Количественные признаки
Измеряемой величиной количественного признака служит его размер, определяемый в соответствующих единицах измерений по шкале отношений (например, рост, вес). Количественные признаки делятся на **дискретные** и **непрерывные**.
