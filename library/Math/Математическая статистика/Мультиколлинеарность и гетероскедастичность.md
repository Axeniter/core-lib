# Мультиколлинеарность и гетероскедастичность

## Мультиколлинеарность
### Определение через матрицу парных корреляций
Для оценки мультиколлинеарности факторов может использоваться **определитель матрицы парных коэффициентов корреляции** $\det|R|$.
- Если бы факторы **не коррелировали** между собой, то матрица парных коэффициентов корреляции была бы **единичной матрицей** (все недиагональные элементы равны нулю): $\det|R| = 1$.
- Если между факторами существует **полная линейная зависимость**, то коэффициенты корреляции равны единице и $\det|R| = 0$.

### Интерпретация
- Чем ближе $\det|R|$ к **0**, тем сильнее мультиколлинеарность факторов и тем **ненадёжнее** результаты множественной регрессии.
- Чем ближе $\det|R|$ к **1**, тем **меньше** мультиколлинеарность.

### Проверка гипотезы о независимости переменных
$$H_0: \det|R| = 1$$
$$H_1: \det|R| \neq 1$$
Используется критерий $\chi^2$:

$$\chi^2_{\text{расч}} = -\left(n - 1 - \frac{2p + 5}{6}\right) \cdot \ln(\det|R|)$$
где:
- $n$ — объём выборки,
- $p$ — число факторов.

**Принятие решения:**
- Если $\chi^2_{\text{расч}} > \chi^2_{\text{табл}}$ — $H_0$ **отклоняется**, мультиколлинеарность значима.
- Иначе — $H_0$ принимается.

## Гомоскедастичность и гетероскедастичность
Для применения метода наименьших квадратов требуется, чтобы дисперсия остатков была **гомоскедастичной**. Это значит, что для каждого значения фактора $x_j$ остатки $\varepsilon_i$ имеют одинаковую дисперсию:

$$\sigma^2_{\varepsilon_i} = \sigma^2 = \text{const}$$

В противном случае имеет место **гетероскедастичность**:

$$\sigma^2_{\varepsilon_i} \neq \sigma^2_{\varepsilon_j} \neq \sigma^2, \quad i \neq j$$

## Метод Гольдфельда-Квандта для оценки гетероскедастичности
Применяется при **малом объёме выборки**.

### Алгоритм
1. **Ранжирование** наблюдений по возрастанию фактора $x$.
2. **Исключение** из рассмотрения $C$ центральных наблюдений. При этом должно выполняться:
   $$\frac{n - C}{2} > p$$
   где $p$ — число оцениваемых параметров.
3. **Разделение** совокупности из $n - C$ наблюдений на **две группы** (с малыми и с большими значениями фактора $x$) и построение уравнения регрессии для каждой группы.
4. Определение остаточных сумм квадратов $S_1$ и $S_2$ для каждой группы и нахождение отношения:
   $$R = \frac{S_1}{S_2}$$

### Проверка гипотезы
$H_0$: гомоскедастичность (дисперсии равны).

При выполнении $H_0$ отношение $R$ подчиняется $F$-критерию со степенями свободы:

$$k_1 = k_2 = \frac{n - C - 2p}{2}$$

Чем больше величина $R$ превышает табличное значение $F_{\text{табл}}$, тем сильнее выражена гетероскедастичность.
