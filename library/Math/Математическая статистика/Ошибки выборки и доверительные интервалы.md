# Ошибки выборки и доверительные интервалы
## Ошибка репрезентативности
**Ошибка репрезентативности** — это разница между значениями показателя, полученного по выборке, и генеральным параметром:
$$\Delta = |\tilde{x} - \bar{x}|$$
где:
- $\tilde{x}$ — генеральная средняя,
- $\bar{x}$ — выборочная средняя.

## Средняя ошибка выборочной средней
Среднее квадратическое отклонение выборочных средних от генеральной средней называется **средней ошибкой выборочной средней** и обозначается $\mu$.
Средняя ошибка выборки тем больше, чем больше вариация в генеральной совокупности $\sigma$, и тем меньше, чем больше объём выборки $n$:
$$\mu = \frac{\sigma}{\sqrt{n}}$$
**Коэффициент вариации:**
$$V = \frac{\sigma}{\bar{x}} \cdot 100\%$$
### Оценка генеральной дисперсии
Значение дисперсии в генеральной совокупности, как правило, неизвестно, но может быть оценено через выборочную дисперсию:
$$\sigma^2 = \frac{n}{n - 1} S^2$$
Если $n \to \infty$, то $\frac{n}{n - 1} \to 1$ и $\sigma^2 = S^2$.
Тогда:
$$\mu = \frac{\sigma}{\sqrt{n}} = \frac{S}{\sqrt{n}}$$
Если выборка маленькая:
$$\mu = \frac{S}{\sqrt{n - 1}}$$

## Нормированное отклонение и распределение ошибок
Распределение ошибок выборочных средних имеет характер нормального распределения, если $n \to \infty$.
**Нормированное отклонение** выборочной средней от генеральной средней:
$$t = \frac{|\tilde{x} - \bar{x}|}{\mu} = \frac{\Delta}{\mu}$$
При большом объёме выборки ($n \to \infty$) $t$ определяется по таблице функции Лапласа с заданной вероятностью.

## Доверительная вероятность и предельная ошибка выборки
Вероятность, которая применяется при расчёте ошибок выборочной характеристики, называется **доверительной** и обозначается $q$.
**Стандартные значения доверительной вероятности:**

| $q$      | $t$        |
|----------|------------|
| $0.683$  | $1$        |
| $0.950$  | $1.96 \approx 2$ |
| $0.954$  | $2$        |
| $0.997$  | $3$        |

Ошибка выборки при принятой доверительной вероятности называется **доверительной ошибкой выборки** (предельной ошибкой выборки):
$$\Delta = t \cdot \mu = t \cdot \frac{S}{\sqrt{n}}$$
---
## Доверительный интервал для генеральной средней
$$\bar{x} - t\mu \leq \tilde{x} \leq \bar{x} + t\mu$$

## Случай малой выборки ($n < 30$)
Если $n < 30$, для нормально распределённой генеральной совокупности могут быть рассчитаны доверительные вероятности и доверительные пределы генеральной средней.
В этом случае нормированное отклонение:
$$t = \frac{|\tilde{x} - \bar{x}|}{\mu}, \quad \text{где } \mu = \frac{S}{\sqrt{n - 1}}$$
подчиняется **распределению Стьюдента**.
Распределение Стьюдента имеет один параметр — **число степеней свободы**:
$$k = n - 1$$
Оно равно числу тех индивидуальных значений признака, которыми нужно располагать для определения искомой характеристики.
**Алгоритм построения доверительного интервала:**
1. Задаются $q$ и $k$,
2. По таблице распределения Стьюдента находят $t$,
3. Вычисляют $\Delta = t \cdot \mu$,
4. Строят доверительный интервал.

## Определение необходимого объёма выборки
$$n \geq \frac{t^2 \sigma^2}{\Delta^2}$$
где:
- $\Delta$ — допустимая погрешность,
- $t$ — коэффициент доверия,
- $\sigma$ — среднее квадратическое отклонение.

## Примеры построения доверительных интервалов
### Пример 1 (большая выборка)
**Дано:** $q = 0.954$, $\bar{x} = 11$, $\sigma = 1.7$, $n = 50$.
**Найти:** доверительный интервал для $\tilde{x}$.
**Решение:**
$$\bar{x} - t \cdot \frac{\sigma}{\sqrt{n}} \leq \tilde{x} \leq \bar{x} + t \cdot \frac{\sigma}{\sqrt{n}}$$
$t = 2$ (для $q = 0.954$)
$$\Delta = t \cdot \frac{\sigma}{\sqrt{n}} = 2 \cdot \frac{1.7}{\sqrt{50}} = 0.5$$
**Ответ:** $10.5 \leq \tilde{x} \leq 11.5$

### Пример 2 (малая выборка)
**Дано:** $q = 0.95$, $\bar{x} = 227$, $S = 13.7$, $n = 15$.
**Решение:**
$k = n - 1 = 15 - 1 = 14$
$t = 2$ (по таблице Стьюдента для $q = 0.95$, $k = 14$)
$$\Delta = 2 \cdot \frac{13.7}{\sqrt{14}} = 8$$
**Ответ:** $219 \leq \tilde{x} \leq 235$

## Оценки параметров генеральной совокупности
### Несмещённая оценка генерального среднего (математического ожидания)
$$\bar{x}_B = \frac{\sum n_i x_i}{n}$$
### Смещённая оценка генеральной дисперсии
$$D_B = \frac{\sum n_i (x_i - \bar{x}_B)^2}{n}$$
### Вычисление через условные варианты
Пусть $u_i = x_i - c$. Тогда:
$$\bar{x}_B = c + \frac{\sum n_i u_i}{n}$$
$$D_B(x) = D_B(u)$$
Если $u_i = C x_i$ (где $C = 10^k$), то:
$$D_B(x) = \frac{D_B(u)}{C^2}$$
### Несмещённая оценка генеральной дисперсии
$$S^2 = \frac{n}{n - 1} D_B$$
