## Связь между средним квадратическим отклонением и количеством наблюдений в условиях нормального распределения
При нормальном распределении:

1. В интервале $(\bar{x} - \sigma;\ \bar{x} + \sigma)$ располагается **68.3%** наблюдений.
2. В интервале $(\bar{x} - 2\sigma;\ \bar{x} + 2\sigma)$ располагается **95.4%** наблюдений.
3. В интервале $(\bar{x} - 3\sigma;\ \bar{x} + 3\sigma)$ располагается **99.7%** наблюдений (правило «трёх сигм»).

## Шкала оценки индивидуальных значений
При распределении, близком к нормальному, индивидуальные значения показателей можно оценить по следующей шкале:

$$t_i = \frac{x_i - \bar{x}}{\sigma}$$

где $i$ — номер выбранного испытания.

| Значение $t$ | Оценка |
|-------------|--------|
| $t < -2$    | Низкое |
| $-2 \leq t < -1$ | Ниже среднего |
| $-1 \leq t \leq 1$ | Норма |
| $1 < t \leq 2$ | Выше среднего |
| $t > 2$     | Высокое |
