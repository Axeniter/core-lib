# Прогнозирование в парной регрессии
## Точечный прогноз
Прогнозное значение $y_p$ определяется путём подстановки в уравнение регрессии соответствующего (прогнозного) значения $x_p$:

$$y_p \to \hat{y}_x = a + b x$$

## Стандартная ошибка прогноза
$$m_{y_p} = S_{\text{ост}} \sqrt{1 + \frac{1}{n} + \frac{(x_p - \bar{x})^2}{\sum (x - \bar{x})^2}}$$

где:
$$S_{\text{ост}} = \sqrt{\frac{\sum (y - \hat{y})^2}{n - m - 1}}$$

## Доверительный интервал прогноза
$$\hat{y}_p \pm \Delta y_p; \quad \hat{y}_{p,\min} = \hat{y}_p - \Delta y_p; \quad \hat{y}_{p,\max} = \hat{y}_p + \Delta y_p$$

где предельная ошибка прогноза:
$$\Delta y_p = t_{\text{табл}} \cdot m_{y_p}$$
