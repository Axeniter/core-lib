# Показатели формы распределения
## Асимметрия
Характеризует скошенность распределения.

$$A_s = \frac{\bar{x} - M_0}{\sigma}$$

**Формула Линдберга:**

$$A_s = \Pi - 50$$

где $\Pi$ — процент значений признака, которые превышают величину средней арифметической.

**Через центральный момент третьего порядка:**

$$A_s = \frac{\mu_3}{\sigma^3}$$

где $\mu_3$ — центральный момент третьего порядка.

### Эксцесс
Характеризует островершинность (крутизну) распределения относительно нормального.

$$E_x = \frac{\mu_4}{\sigma^4} - 3$$

где $\mu_4$ — центральный момент четвёртого порядка.
