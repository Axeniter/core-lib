# Метод наименьших квадратов (МНК)
Для оценки параметров регрессии, линейной по параметрам, используется **метод наименьших квадратов (МНК)**. МНК позволяет получить такие оценки параметров, при которых сумма квадратов отклонений фактических значений результативного признака от теоретических минимальна:

$$\sum (y - \hat{y}_x)^2 \to \min$$

## Система нормальных уравнений для парной линейной регрессии

$$\begin{cases}
na + b \sum x = \sum y \\
a \sum x + b \sum x^2 = \sum yx
\end{cases}$$

## Решение системы

$$a = \bar{y} - b \bar{x}$$

$$b = \frac{\text{cov}(x, y)}{\sigma_x^2} = \frac{\overline{yx} - \bar{y}\bar{x}}{\overline{x^2} - (\bar{x})^2}$$
