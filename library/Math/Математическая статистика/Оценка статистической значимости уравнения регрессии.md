# Оценка статистической значимости уравнения регрессии
## F-тест (критерий Фишера)
$F$-тест служит для оценивания качества уравнения регрессии. Состоит в проверке гипотезы о статистической значимости уравнения регрессии в целом.
### Расчётное значение для парной регрессии
$$F_{\text{факт}} = \frac{\sum (\hat{y}_x - \bar{y})^2 / m}{\sum (y - \hat{y})^2 / (n - m - 1)} = \frac{R^2}{1 - R^2} \cdot (n - 2)$$
где:
- $n$ — число единиц совокупности (наблюдений),
- $m$ — число параметров уравнения регрессии (для парной линейной $m = 1$).
### Принятие решения
- Если $F_{\text{факт}} < F_{\text{крит}}$ — нулевая гипотеза о статистической незначимости уравнения регрессии **не отклоняется** (уравнение считается статистически незначимым).
- Если $F_{\text{факт}} \geq F_{\text{крит}}$ — нулевая гипотеза **отклоняется**, уравнение регрессии признаётся статистически значимым.
$F_{\text{крит}}$ — табличное значение критерия Фишера для заданного уровня значимости и степеней свободы $k_1 = m$, $k_2 = n - m - 1$.

## t-критерий Стьюдента для коэффициентов регрессии и корреляции
Для оценки статистической значимости коэффициентов регрессии и корреляции используется $t$-критерий Стьюдента.
Выдвигается гипотеза о случайной природе коэффициента, т.е. о его незначимом отличии от нуля.
### Фактические значения t-статистики
$$t_b = \frac{b}{m_b}, \quad t_a = \frac{a}{m_a}, \quad t_r = \frac{r}{m_r}$$
где $m_b$, $m_a$, $m_r$ — стандартные ошибки соответствующих коэффициентов.
### Принятие решения
- Если $|t_{\text{факт}}| < t_{\text{крит}}$ — нулевая гипотеза **не отклоняется** (коэффициент статистически незначим).
- Если $|t_{\text{факт}}| \geq t_{\text{крит}}$ — нулевая гипотеза **отклоняется** (коэффициент статистически значим).
$t_{\text{крит}}$ — табличное значение критерия Стьюдента для заданного уровня значимости и числа степеней свободы $df = n - m - 1$.
