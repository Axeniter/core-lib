# Метод наискорейшего градиентного спуска
## Метод
Метод наискорейшего градиентного спуска для решения систем линейных алгебраических уравнений (СЛАУ) — это итерационный метод, основанный на сведении задачи решения СЛАУ к задаче минимизации квадратичной функции.
## Задача минимизации
Пусть дана система:
$$
A\mathbf{x} = \mathbf{b}
$$
где $A$ — **симметричная, положительно определенная матрица** ($A = A^T > 0$), $\mathbf{x}$ — искомый вектор, $\mathbf{b}$ — вектор правой части.

Для такой матрицы решение СЛАУ эквивалентно поиску точки минимума квадратичного функционала (функции многих переменных):
$$
F(\mathbf{x}) = \frac{1}{2}(A\mathbf{x}, \mathbf{x}) - (\mathbf{b}, \mathbf{x})
$$
где $(\cdot, \cdot)$ — скалярное произведение.

Найдем градиент $F(\mathbf{x})$:
$$
\nabla F(\mathbf{x}) = A\mathbf{x} - \mathbf{b}
$$
В точке минимума градиент равен нулю:
$$
\nabla F(\mathbf{x}^*) = 0 \quad \Leftrightarrow \quad A\mathbf{x}^* - \mathbf{b} = 0 \quad \Leftrightarrow \quad A\mathbf{x}^* = \mathbf{b}
$$
Поскольку матрица положительно определена, это единственный минимум (функция выпукла).

Таким образом, вместо решения $A\mathbf{x} = \mathbf{b}$ мы ищем минимум $F(\mathbf{x})$.

## Идея градиентного спуска
Начинаем с произвольного начального приближения $\mathbf{x}_0$ и двигаемся итерационно по схеме:
$$
\mathbf{x}_{k+1} = \mathbf{x}_k - \alpha_k \nabla F(\mathbf{x}_k)
$$
Поскольку $\nabla F(\mathbf{x}_k) = A\mathbf{x}_k - \mathbf{b} = -\mathbf{r}_k$, где $\mathbf{r}_k = \mathbf{b} - A\mathbf{x}_k$ — **невязка**, то шаг можно записать как:
$$
\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{r}_k
$$
То есть мы движемся в направлении невязки (антиградиента).

### Выбор шага $\alpha_k$: наискорейший спуск
Ключевой момент — наискорейший спуск означает, что на каждом шаге мы выбираем такой коэффициент $\alpha_k$, который доставляет **минимум функции вдоль направления $\mathbf{r}_k$**:
$$
\alpha_k = \arg\min_{\alpha} F(\mathbf{x}_k + \alpha \mathbf{r}_k)
$$

Подставим $\mathbf{x}_k + \alpha \mathbf{r}_k$ в функционал:
$$
F(\mathbf{x}_k + \alpha \mathbf{r}_k) = \frac{1}{2}(A(\mathbf{x}_k + \alpha \mathbf{r}_k), \mathbf{x}_k + \alpha \mathbf{r}_k) - (\mathbf{b}, \mathbf{x}_k + \alpha \mathbf{r}_k)
$$
Раскроем скобки, пользуясь симметрией $A$:
$$
F(\mathbf{x}_k + \alpha \mathbf{r}_k) = F(\mathbf{x}_k) - \alpha(\mathbf{r}_k, \mathbf{r}_k) + \frac{\alpha^2}{2}(A\mathbf{r}_k, \mathbf{r}_k)
$$
Это квадратичная функция по $\alpha$ с положительным старшим коэффициентом. Найдем её минимум, приравняв производную по $\alpha$ к нулю:
$$
\frac{d}{d\alpha}F(\mathbf{x}_k + \alpha \mathbf{r}_k) = -(\mathbf{r}_k, \mathbf{r}_k) + \alpha (A\mathbf{r}_k, \mathbf{r}_k) = 0
$$
Отсюда оптимальный шаг:
$$
\boxed{\alpha_k = \frac{(\mathbf{r}_k, \mathbf{r}_k)}{(A\mathbf{r}_k, \mathbf{r}_k)}}
$$


### 4. Алгоритм
1.  **Начало:** Выбираем $\mathbf{x}_0$ (например, нулевой вектор), вычисляем $\mathbf{r}_0 = \mathbf{b} - A\mathbf{x}_0$.
2.  **Итерация $k = 0, 1, 2, \dots$:**
    *   Если $\|\mathbf{r}_k\| < \varepsilon$, остановка (решение найдено).
    *   Вычисляем вектор $A\mathbf{r}_k$ (умножение матрицы на вектор).
    *   Вычисляем шаг: $\alpha_k = \frac{(\mathbf{r}_k, \mathbf{r}_k)}{(A\mathbf{r}_k, \mathbf{r}_k)}$.
    *   Обновляем приближение: $\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{r}_k$.
    *   Обновляем невязку: $\mathbf{r}_{k+1} = \mathbf{b} - A\mathbf{x}_{k+1} = \mathbf{r}_k - \alpha_k A\mathbf{r}_k$.
3.  **Конец.**

*   **Скорость сходимости:** линейная. Ошибка убывает как:
    $$
    \|\mathbf{x}_k - \mathbf{x}^*\|_A \le \left(\frac{\lambda_{\max} - \lambda_{\min}}{\lambda_{\max} + \lambda_{\min}}\right)^k \|\mathbf{x}_0 - \mathbf{x}^*\|_A
    $$
    где $\lambda$ — собственные числа матрицы $A$.
