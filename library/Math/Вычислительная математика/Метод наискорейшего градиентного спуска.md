# Метод наискорейшего градиентного спуска
## Метод
Распространенным методом минимизации функций большого числа переменных является **метод градиентного спуска**. Последующее приближение получается из предыдущего смещением в направлении, противоположном градиенту функции $F(x)$. Каждое следующее приближение ищется в виде  
$$x^{n+1} = x^n - \delta_n \, \text{grad } F(x^n). \tag{1}$$

Приведенное описание не определяет алгоритм однозначно, поскольку ничего не сказано о выборе параметра $\delta_n$. Например, его можно определить из условия минимума величины  
$$F(x^n - \delta_n \, \text{grad } F(x^n)). \tag{2}$$

В этом случае рассматриваемый метод называют **методом наискорейшего градиентного спуска** или просто **методом наискорейшего спуска**.

Для функции $F(x) = (Ax, x) - 2(b, x)$, соответствующей системе линейных уравнений с матрицей $A = A^T > 0$, задача нахождения минимума решается в явном виде. В этом конкретном случае
$$\text{grad } F = 2(Ax - b)$$
и
$$x^{n+1} = x^n - 2\delta_n(Ax^n - b).$$

Обозначим $2\delta_n$ через $\Delta_n$, т. е. положим
$$x^{n+1} = x^n - \Delta_n(Ax^n - b). \tag{3}$$

Пусть $\varphi(\Delta_n) = F(x^{n+1})$. Вспоминая, что $A = A^T$, вычислим $\varphi'(\Delta_n)$.
Имеем
$$\varphi(\Delta_n) = F(x^n) - 2\Delta_n(Ax^n - b, Ax^n - b) + (A(Ax^n - b), Ax^n - b)\Delta_n^2.$$

Приравнивая производную $\varphi'(\Delta_n)$ к нулю, получаем:
$$-2(Ax^n - b, Ax^n - b) + 2\Delta_n(A(Ax^n - b), Ax^n - b) = 0,$$
откуда
$$\Delta_n = \frac{(Ax^n - b, Ax^n - b)}{(A(Ax^n - b), Ax^n - b)}. \tag{4}$$
## Теорема
**Теорема.** Приближения метода наискорейшего спуска удовлетворяют соотношению:
$$
F_0(x^n) \leq \left( \frac{M - \mu}{M + \mu} \right)^{2n} F_0(x^0), \quad F_0(x) = (A(x - X), x - X)
$$
