# Метод последовательной верхней релаксации
Рассмотрим два последовательных приближения в [[Метод Зейделя|методе Зейделя]]:
$$y = (x_1^{(k+1)}, \dots, x_{i-1}^{(k+1)}, x_i^{(k)}, \dots, x_n^{(k)})^*,$$
$$z = (x_1^{(k+1)}, \dots, x_{i-1}^{(k+1)}, x_i^{(k+1)}, x_{i+1}^{(k)}, \dots, x_n^{(k)})^*.$$

Для того, чтобы наиболее простым способом перейти к следующему методу последовательной релаксации, посмотрим на приближения в методе Зейделя ещё с одной точки зрения. Обозначим через $t$ и $r$ соответственно невязки приближений $y$ и $z$:

$$t = Ay - f, \quad r = Az - f.$$

Из расчётной формулы метода Зейделя следует, что $r_i = 0$.  
С другой стороны, обозначим $\alpha = x_i^{(k+1)} - x_i^{(k)}$ и выразим $x_i^{(k+1)}$ через $x_i^{(k)}$:

$$x_i^{(k+1)} = x_i^{(k)} + \alpha.$$

Таким образом, поправка $\alpha$ к значению $i$-той компоненты находится из условия

$$r_i = t_i - a_{ii}\alpha = 0,$$

Обнуление $i$-той компоненты невязки обычно называют **полной релаксацией**.  
По этой причине метод Зейделя называют методом полной релаксации.  

Иногда можно добиться более быстрой сходимости, если требовать не обнуления $r_i$, а всего лишь уменьшения $|r_i|$ по сравнению с $|t_i|$, то есть проводить не полную, а **частичную релаксацию**. Итак, потребуем, чтобы $|r_i| = (1 - \omega)t_i < |t_i|$, или $|\alpha - (t_i/a_{ii})| < |t_i/a_{ii}|$.  

Если $t_i/a_{ii} > 0$, то $0 < \omega < 2$; если $t_i/a_{ii} < 0$, то также $0 < \omega < 2$.  
И в том, и в другом случае решение неравенства можно записать в единообразном виде

$$\alpha = \omega \cdot \frac{t_i}{a_{ii}}, \quad \text{где } \omega \in (0, 2).$$

При этом $i$-тая компонента невязки будет определяться формулой

$$r_i = t_i - \omega t_i = (1 - \omega)t_i. \tag{1}$$

Мы получили семейство методов, которые называются **методами последовательной релаксации**. При $\omega = 1$ имеем $r_i = 0$, то есть метод Зейделя получается из семейства методов последовательной релаксации как частный случай. Параметр $\omega$ называется **релаксационным параметром**.

Подставляя в формулу (1) выражения для $r_i$ и $t_i$, нетрудно получить расчетные формулы метода последовательной релаксации:

$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( \omega f_i - \omega \sum_{j=1}^{i-1} a_{ij}x_j^{(k+1)} - \omega \sum_{j=i+1}^n a_{ij}x_j^{(k)} + (1 - \omega)a_{ii}x_i^{(k)} \right),$$

или в более компактной форме:

$$x_i^{(k+1)} = x_i^{(k)} - \omega \frac{(A x^{(k)} - f)_i}{a_{ii}}.$$

Эту же формулу можно получить, исходя из канонической формы записи при $B = D + \omega A_L$, $\tau = \omega$.

## Достаточное условие сходимости метода последовательной релаксации
Для симметрических положительно определённых матриц метод последовательной релаксации сходится, если $\omega \in (0, 2)$.
