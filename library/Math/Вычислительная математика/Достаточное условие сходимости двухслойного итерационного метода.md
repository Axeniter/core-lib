# Достаточное условие сходимости
## Теорема
Для сходимости метода при любом начальном приближении достаточно, чтобы хотя бы одна из норм матрицы перехода, согласованная с какой-либо векторной нормой, была меньше 1.
## Доказательство
Покажем сначала, что модуль любого собственного значения матрицы не превосходит её согласованной нормы.  
Пусть $Su = \lambda u$, $u \neq 0$. Имеем  

$$|\lambda| \cdot \|u\| = \|\lambda u\| = \|Su\| \leq \|S\| \cdot \|u\|$$

Поделив крайние части неравенства на $\|u\|$ ($u \neq 0$), имеем  

$$|\lambda| \leq \|S\|$$

Пусть теперь $\|S\| < 1$. В силу последнего неравенства все собственные значения матрицы перехода $S$ по модулю меньше 1, и из [[Критерий сходимости двухслойного итерационного метода|критерия сходимости]] следует сходимость метода при любом начальном приближении. Теорема доказана.  

Из теоремы для различных конкретных норм получаются достаточные условия сходимости итерационных методов в терминах матрицы перехода.  
Например:
$$\max_{1 \leq i \leq n} \sum_{j=1}^n |s_{ij}| < 1$$
