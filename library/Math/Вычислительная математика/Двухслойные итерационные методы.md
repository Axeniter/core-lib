# Двухслойные итерационные методы
## Общий вид
Будем рассматривать двухслойные итерационные методы решения системы $Ax = f$, каждый из которых можно записать в каноническом виде:

$$\frac{B(x^{(k+1)} - x^{(k)})}{\tau_k} + Ax^{(k)} = f, \quad k = 0, 1, 2, \dots \tag{1}$$

здесь:
- $B$ — некоторая невырожденная матрица,
- $\tau_k$ — итерационный параметр,
- $x^{(0)}$ — произвольное начальное приближение (например нулевой вектор).

## Стационарный метод
Если при $\forall k$, $\tau_k = \tau = const$, то метод называется стационарным. В основном мы будем рассматривать именно стационарные двухслойные итерационные методы.

$$\frac{B(x^{(k+1)} - x^{(k)})}{\tau} + Ax^{(k)} = f, \quad k = 0, 1, 2, \dots \tag{2}$$

Предполагая, что $A$ — невырожденная, покажем, что если метод сходится, то он обязательно сходится к единственному решению $x^*$ системы $Ax = f$.

Действительно, пусть $\lim_{k \to \infty} x^{(k)} = x^*$. Переходя в методе (2) к пределу при $k\to \infty$, получаем:

$$\frac{B}{\tau} \cdot (\lim_{k \to \infty} x^{(k+1)} - \lim_{k \to \infty} x^{(k)}) + A \cdot \lim_{k \to \infty} x^{(k)} = f \implies A\bar{x} = f$$

Отсюда, в силу единственности решения системы $Ax = f$, следует, что $\bar{x} = x^*$.

Выбирая $B$ и $\tau$, нужно помнить о самом факте сходимости последовательности приближений. Вычисляя очередное приближение $x^{(k+1)}$ необходимо решать систему:

$$Bx^{(k+1)} = (B - \tau A)x^{(k)} + \tau f$$

Трудоёмкость решения этой системы зависит от структуры матрицы $B$. Поскольку в общем случае приходится решать много таких систем, то $B$ выбирают так, чтобы решение каждой такой системы осуществлялось как можно проще. Поэтому в качестве $B$ обычно используют матрицу с простой структурой: диагональную или треугольную матрицу.  
## Невязка и погрешность
$$z^{(k)} = x^{(k)} - x^* \quad \text{ — вектор ошибки (погрешности) } k\text{-го приближения;}$$
$$r^{(k)} = Ax^{(k)} - f \quad \text{ — вектор невязки } k\text{-го приближения;}$$
Невязка показывает насколько решение вяжется с системой.

Тогда условие сходимости итерационного процесса принимает вид:  
$$\|z^{(k)}\| \to 0, \quad k \to \infty \quad \lim_{k \to \infty} \|z^{(k)}\| = 0$$
## Матрица перехода
Перепишем итерационный процесс (2) через $z^{(k)}$.

Исходный метод:
$$\frac{B(x^{(k+1)} - x^{(k)})}{\tau} + Ax^{(k)} = f$$
Подставляем $x^{(k)} = z^{(k)} + x^*$ и $f = A x^*$ в итерационную схему:
$$B \frac{(z^{(k+1)} + x^*) - (z^{(k)} + x^*)}{\tau} + A(z^{(k)} + x^*) = A x^*$$
Сокращаем $x^*$ в первой скобке и раскрываем $A(z^{(k)} + x^*)$:
$$B \frac{z^{(k+1)} - z^{(k)}}{\tau} + A z^{(k)} + A x^* = A x^*$$
$A x^*$ в левой и правой частях взаимно сокращаются:
$$B \frac{z^{(k+1)} - z^{(k)}}{\tau} + A z^{(k)} = 0$$
Умножаем обе части на $\tau$:
$$B(z^{(k+1)} - z^{(k)}) + \tau A z^{(k)} = 0$$
Раскрываем скобки:
$$B z^{(k+1)} - B z^{(k)} + \tau A z^{(k)} = 0$$
Переносим члены с $z^{(k)}$ в правую часть:
$$B z^{(k+1)} = B z^{(k)} - \tau A z^{(k)}$$
Выносим $z^{(k)}$ за скобку справа:
$$B z^{(k+1)} = (B - \tau A) z^{(k)}$$
Домножаем слева на $B^{-1}$:
$$z^{(k+1)} = B^{-1}(B - \tau A) z^{(k)} = (I - \tau B^{-1}A) z^{(k)}$$

Таким образом,
$$z^{(k+1)} = S z^{(k)}, \quad S = I - \tau B^{-1}A$$
Или по индукции:
$$z^{(k)} = S^k z^{(0)}$$
Матрица $S$ называется **матрицей перехода** двухслойного итерационного метода.  
Свойства сходимости метода целиком определяются матрицей перехода.
## Асимптотическая скорость сходимости
Из соотношения $z^{(k+1)} = S z^{(k)}$ следует, что норма ошибки на $k$-м шаге оценивается через норму матрицы перехода $S$ и норму начальной ошибки:
$$\|z^{(k)}\| = \|S^k z^{(0)}\| \leq \|S\|^k \cdot \|z^{(0)}\|$$

Для сходимости метода необходимо, чтобы ошибка убывала. Это гарантируется, если норма матрицы перехода меньше единицы.
**Требование сходимости:** $\|S\| < 1$.

### Оценка числа итераций для уменьшения ошибки в $e$ раз
Поставим задачу: найти минимальное число итераций $k$, при котором начальная ошибка уменьшится хотя бы в $e$ раз (где $e = \exp(1) \approx 2.718$). То есть ищем $k$, для которого выполняется:
$$\|z^{(k)}\| \leq \frac{1}{e} \|z^{(0)}\|$$

Подставляем верхнюю оценку $\|z^{(k)}\| \leq \|S\|^k \|z^{(0)}\|$. Если мы обеспечим выполнение более сильного неравенства $\|S\|^k \|z^{(0)}\| \leq \frac{1}{e} \|z^{(0)}\|$, то требуемая точность будет заведомо достигнута.

Сокращаем $\|z^{(0)}\|$ (предполагая, что начальное приближение не является точным решением):
$$\|S\|^k \leq \frac{1}{e}$$

Логарифмируем обе части неравенства. Так как $\|S\| < 1$, величина $\ln \|S\|$ отрицательна, и при делении на неё знак неравенства меняется на противоположный:
$$k \ln \|S\| \leq -1 \quad \implies \quad k \geq \frac{1}{-\ln \|S\|}$$

### Определение асимптотической скорости сходимости
Полученное неравенство показывает, что число итераций $k$, необходимое для уменьшения ошибки в $e$ раз, обратно пропорционально величине $-\ln \|S\|$.

Чем больше значение $-\ln \|S\|$, тем меньше итераций требуется для достижения заданной точности. Эта величина характеризует быстроту убывания ошибки и называется **асимптотической скоростью сходимости**:
$$R = -\ln \|S\|$$
