# Метод простой итерации
Полагая в методе:
$$\frac{B(x^{(k+1)} - x^{(k)})}{\tau} + Ax^{(k)} = f, \quad k = 0, 1, 2, \dots$$
$B = I$, получаем метод простой итерации. Матрица перехода имеет вид:
$$S = I - \tau B^{-1} A = I - \tau A.$$

а решение системы находится по явным формулам:  
$$x^{(k+1)} = x^{(k)} - \tau (A x^{(k)} - f)$$
$$x_i^{(k+1)} = \tau f_i + (1 - \tau a_{ii}) x_i^{(k)} - \tau \sum_{j \neq i} a_{ij} x_j^{(k)}, \quad i = \overline{1, n}$$
Поставим следующую задачу оптимизации: подобрать $\tau > 0$ так, чтобы асимптотическая скорость сходимости $R = -\ln \|S\|$ была наибольшей. Из формулы для $R$ видно, что для решения этой задачи следует минимизировать $\|S\|$.

Решим эту задачу в наиболее простом случае, когда $A = A^T > 0$ (матрица симметрична и положительно определена), собственные значения такой матрицы вещественны и положительны.

Обозначим через $\alpha$ и $\beta$ соответственно min и max собственные значения $A$, тогда $0 < \alpha \leq \lambda(A) \leq \beta$.

Используем спектральную норму, т.е. минимизируем $\|S\|_2$. Матрица $S$ также является симметрической, и выполняется:
$$\|S\|_2 = \max_{1 \leq i \leq n} |\lambda_i(S)|$$

Очевидно, $\lambda(S) = 1 - \tau \lambda(A)$, поэтому наша задача состоит в минимизации по $\tau$ величины  
$$\|S\|_2 = \max_{1 \leq i \leq n} |1 - \tau \lambda_i(A)|$$

Для этого рассмотрим функцию  
$$f(\tau, \lambda) = |1 - \tau \lambda|, \quad \forall \tau > 0, \, \lambda \in [\alpha, \beta]$$

Покажем, что при фиксированном $\tau$
$$\max_{\alpha \leq \lambda \leq \beta} f(\tau, \lambda) = \max(f(\tau, \alpha), f(\tau, \beta)) \tag{1}$$

Пусть $\frac{1}{\beta} \leq \tau \leq \frac{1}{\alpha}$. Имеем
$$1 - \tau \alpha \geq 1 - \frac{1}{\alpha} \cdot \alpha = 0, \quad 1 - \tau \beta \leq 1 - \frac{1}{\beta} \cdot \beta = 0$$

то есть на $[\alpha, \beta]$ линейная функция $1 - \tau \lambda$ меняет знак с «+» на «-».

График функции $f(\tau, \lambda) = |1 - \tau \lambda|$ в таком случае имеет "V"-образный вид, и утверждение (1) становится очевидным.

Аналогичным образом оно доказывается и для случаев
$$\frac{1}{\tau} < \alpha \quad \text{и} \quad \frac{1}{\tau} > \beta$$

Ясно, что:
$$\max_{1 \leq i \leq n} |1 - \tau \lambda_i(A)| = \max_{\alpha \leq \lambda \leq \beta} f(\tau, \lambda) = \max(f(\tau, \alpha), f(\tau, \beta))$$
С другой стороны:
$$\max_{1 \leq i \leq n} |1 - \tau \lambda_i(A)| \geq \max(|1 - \tau \alpha|, |1 - \tau \beta|) = \max(f(\tau, \alpha), f(\tau, \beta))$$

Следовательно:
$$\|S\|_2 = \max_{1 \leq i \leq n} |1 - \tau \lambda_i(A)| = \max(f(\tau, \alpha), f(\tau, \beta))$$

Теперь покажем, что решением этой задачи является $\tau_0 = \frac{2}{\alpha + \beta}$:
$$1 - \tau_0 \alpha = 1 - \frac{2\alpha}{\alpha + \beta} = \frac{\beta - \alpha}{\alpha + \beta} > 0, \quad 1 - \tau_0 \beta = 1 - \frac{2\beta}{\alpha + \beta} = \frac{\alpha - \beta}{\alpha + \beta} < 0$$
$$f(\tau_0, \alpha) = |1 - \tau_0 \alpha| = \frac{\beta - \alpha}{\alpha + \beta}, \quad f(\tau_0, \beta) = |1 - \tau_0 \beta| = \frac{\beta - \alpha}{\alpha + \beta}$$

Итак, $\max(f(\tau_0, \alpha), f(\tau_0, \beta)) = \frac{\beta - \alpha}{\alpha + \beta}$.

Нам осталось показать, что при всех $\tau \neq \tau_0$
$$\max(f(\tau, \alpha), f(\tau, \beta)) > \frac{\beta - \alpha}{\alpha + \beta}$$

1. Пусть $\tau \leq \tau_0$, тогда
$$1 - \tau \alpha \geq 1 - \tau_0 \alpha = \frac{\beta - \alpha}{\alpha + \beta} > 0$$
$$f(\tau, \alpha) = 1 - \tau \alpha > \frac{\beta - \alpha}{\alpha + \beta}$$
$$\max(f(\tau, \alpha), f(\tau, \beta)) \geq f(\tau, \alpha) > \frac{\beta - \alpha}{\alpha + \beta}$$
2. Пусть $\tau \geq \tau_0$, тогда
$$1 - \tau \beta \leq 1 - \tau_0 \beta = -\frac{\beta - \alpha}{\alpha + \beta} < 0$$
$$f(\tau, \beta) = |1 - \tau \beta| > \frac{\beta - \alpha}{\alpha + \beta}$$
$$\max(f(\tau, \alpha), f(\tau, \beta)) \geq f(\tau, \beta) > \frac{\beta - \alpha}{\alpha + \beta}$$

Мы показали, что действительно значение $\tau_0 = \frac{2}{\alpha + \beta}$ является таким, что
$$\min_{\tau} \|S\|_2 = \max(f(\tau_0, \alpha), f(\tau_0, \beta)) = \frac{\beta - \alpha}{\alpha + \beta} < 1$$

Последнее неравенство гарантирует сходимость метода простой итерации с оптимальным значением итерационного параметра.

Асимптотическая скорость сходимости:
$$R = -\ln \|S\|_2 = -\ln \left( \frac{\beta - \alpha}{\beta + \alpha} \right)$$

Преобразуем последнее выражение. Так как $A = A^T > 0$, то:
$$\mu_2(A) = \|A\|_2 \cdot \|A^{-1}\|_2 = \max \lambda(A) \cdot \max \lambda(A^{-1}) = \max \lambda(A) \cdot \max \frac{1}{\lambda(A)} = \frac{\beta}{\min \lambda(A)} = \frac{\beta}{\alpha}$$

Тогда
$$R = \ln \frac{\beta + \alpha}{\beta - \alpha} = \ln \frac{1 + \frac{\beta}{\alpha}}{1 - \frac{\beta}{\alpha}} = \ln \frac{\mu_2(A) + 1}{\mu_2(A) - 1}$$

Скорость сходимости итерационного метода тем выше, чем лучше обусловлена матрица системы, т.е. чем меньше $\mu_2(A)$.
