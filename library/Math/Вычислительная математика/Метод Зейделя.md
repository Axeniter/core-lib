# Метод Зейделя
## Метод
Полагая $B = A_L + D$, $\tau = 1$, получим:
$$(A_L + D)(x^{(k+1)} - x^{(k)}) + (A_L + D + A_R)x^{(k)} = f, \quad k = 0, 1, \dots$$
$$(A_L + D)x^{(k+1)} = f - A_R x^{(k)}$$
Так как $A_L + D$ — нижняя треугольная матрица, то явные формулы:
$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( f_i - \sum_{j=1}^{i-1} a_{ij}x_j^{(k+1)} - \sum_{j=i+1}^n a_{ij}x_j^{(k)} \right), \quad i = \overline{1, n}$$
Матрица перехода
$$S = I - \tau B^{-1} A = I - (D + A_L)^{-1}(A_L + D + A_R) = -(D + A_L)^{-1}A_R$$

Для выяснения условий сходимости воспользуемся критерием сходимости, сформулированным в терминах матрицы перехода, а именно: необходимо и достаточно, чтобы все собственные значения $|\lambda(S)| < 1$.

Собственные значения матрицы $S$ являются корнями уравнения:
$$\det\left[-(A_L + D)^{-1}A_R - \lambda I\right] = 0 \tag{*}$$
Но
$$\det\left[-(A_L + D)^{-1}A_R - \lambda I\right] = \det\left[-(A_L + D)^{-1}(A_R + \lambda(A_L + D))\right] = \det\left[-(A_L + D)^{-1}\right] \cdot \det\left[A_R + \lambda(A_L + D)\right]$$

Так как $A_L + D$ — невырожденная матрица, то уравнение $(*)$ эквивалентно уравнению:
$$\det\left[\lambda(A_L + D) + A_R\right] = 0 \tag{**}$$

Тем самым доказана теорема (критерий):
Для того, чтобы метод Зейделя сходился при любом начальном приближении, необходимо и достаточно, чтобы все корни уравнения $\det\left[\lambda(A_L + D) + A_R\right] = 0$ были по модулю меньше единицы.
## Теорема (достаточное условие)
Если матрица $A$ системы уравнений $Ax = f$ имеет строгое диагональное преобладание, то метод Зейделя сходится при любом начальном приближении.
### Доказательство
Пусть $\lambda$ — произвольный корень уравнения (**).

Матрица $\lambda(A_L + D) + A_R$ вырождена, поэтому по следствию из теоремы Адамара у неё нарушено, по крайней мере, одно строгое условие Адамара, т.е. существует такое $k$ ($1 \leq k \leq n$), что:
$$|\lambda \cdot a_{kk}| \leq \sum_{j=1}^{k-1} |\lambda \cdot a_{kj}| + \sum_{j=k+1}^n |a_{kj}|$$
Отсюда легко получить оценку сверху для $|\lambda|$:
$$|\lambda| \cdot |a_{kk}| \leq |\lambda| \sum_{j=1}^{k-1} |a_{kj}| + \sum_{j=k+1}^n |a_{kj}|$$
$$|\lambda| \left( |a_{kk}| - \sum_{j=1}^{k-1} |a_{kj}| \right) \leq \sum_{j=k+1}^n |a_{kj}|$$

По условию матрица $A$ имеет строгое диагональное преобладание, т.е. для неё выполнены все строгие условия Адамара, в том числе $k$-ое:
$$|a_{kk}| > \sum_{j=1}^{k-1} |a_{kj}| + \sum_{j=k+1}^n |a_{kj}|$$

Отсюда следует, что
$$\sum_{j=k+1}^n |a_{kj}| < |a_{kk}| - \sum_{j=1}^{k-1} |a_{kj}|$$

Подставляя это в неравенство для $|\lambda|$, получаем:
$$|\lambda| \left( |a_{kk}| - \sum_{j=1}^{k-1} |a_{kj}| \right) < |a_{kk}| - \sum_{j=1}^{k-1} |a_{kj}|$$

Так как выражение в скобках положительно (в силу строгого диагонального преобладания), то $|\lambda| < 1$. Теорема доказана.
## Теорема
Если матрица $A$ системы $Ax = f$ симметричная и положительно определённая, то метод Зейделя сходится при любом начальном приближении.
