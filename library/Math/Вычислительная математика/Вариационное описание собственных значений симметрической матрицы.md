# Вариационное описание собственных значений симметрической матрицы
## Исходные положения
Пусть $A = A^*$ — некоторая симметрическая матрица. Известно, что для всякой симметрической матрицы $A$ существует такая ортогональная матрица $U$ ($U^*U = I$), что
$$U^*AU = \Lambda$$

где $\Lambda$ — диагональная матрица. Так как для ортогональной матрицы $U^* = U^{-1}$, то матрицы $A$ и $\Lambda$ подобны. Подобные матрицы имеют одинаковые собственные значения. Но собственные значения диагональной матрицы равны её диагональным элементам. Следовательно, диагонали $\Lambda$ являются собственными значениями матрицы $A$:
$$\Lambda = \begin{pmatrix}
\lambda_1(A) & & 0 \\
& \ddots & \\
0 & & \lambda_n(A)
\end{pmatrix}$$

Столбцы матрицы $U$ - собственные векторы матрицы $A$.

*Доказательство.* Обозначим $l$-й столбец $U$ через $u^{(l)}$. Домножаем равенство на $U$ слева и получаем: $AU = U\Lambda$. Очевидно, $l$-й столбец $AU$ есть $Au^{(l)}$, а $l$-й столбец $U\Lambda$ есть $\lambda_l(A)u^{(l)}$. Следовательно выполняется $Au^{(l)} = \lambda_l(A)u^{(l)}$, то есть действительно $u^{(l)}$ является собственным вектором матрицы $A$, отвечающим её собственному значению $\lambda_l(A)$. 

Отметим, что собственные векторы матрицы $A$, являясь столбцами ортогональной матрицы $U$, образуют полную ортонормированную систему.

В дальнейшем будем предполагать, что собственные значения матрицы $A$ занумерованы в порядке неубывания: $\lambda_1(A) \leq \lambda_2(A) \leq \cdots \leq \lambda_n(A)$.

## Отношение Рэлея
*Определение.* **Отношение Рэлея** для матрицы A и ненулевого вектора x — это скалярная величина:
$$
R_{A}(x)=\frac{\langle Ax, x \rangle}{\langle x, x \rangle}
$$
Для симметричной (эрмитовой) матрицы отношение Рэлея всегда вещественно.
## Первое вариационное описание
### Формула
$$\min_{\substack{x \neq 0 \\ (x, u^{(1)}) = 0 \\ \vdots \\ (x, u^{(i-1)}) = 0}} \frac{(Ax, x)}{(x, x)} = \lambda_i(A), \quad i = 1, 2, \dots, n$$
Пояснение:
- $u^{(1)}, \ldots, u^{(i-1)}$ — собственные векторы, отвечающие первым $i-1$ наименьшим собственным значениям.
- Мы ищем минимум отношения Рэлея по всем ненулевым векторам, ортогональным этим $i-1$ векторам.
- Этот минимум равен $i$-му собственному значению $\lambda_i(A)$.
- Минимум достигается на $i$-м собственном векторе $u^{(i)}$.
Частные случаи:
- $i=1$: минимум по всему пространству ($\min_{x \neq 0} R_A(x)$) = $\lambda_1(A)$.
- $i=2$: минимум по векторам, ортогональным $u^{(1)}$ = $\lambda_2(A)$.
- $i=n$: минимум по векторам, ортогональным $u^{(1)}, \ldots, u^{(n-1)}$ = $\lambda_n(A)$.
### Вывод
Для его преобразования воспользуемся представлением матрицы $A = U \Lambda U^*$ и тем, что $U$ - ортогональная ($UU^*=I$). Имеем:
$$\frac{(Ax, x)}{(x, x)} = \frac{(U \Lambda U^* x, x)}{(x, x)} =\frac{(\Lambda U^* x, U^* x)}{(UU^* x, x)}= \frac{(\Lambda U^* x, U^* x)}{(U^* x, U^* x)} = \frac{(\Lambda y, y)}{(y, y)}$$

где использована замена $y = U^* x$, или $x = U y$. В силу невырожденности матриц:
$$\min_{x \neq 0} \frac{(Ax, x)}{(x, x)} = \min_{y \neq 0} \frac{(\Lambda y, y)}{(y, y)}$$

Покажем, что
$$\min_{y \neq 0} \frac{(\Lambda y, y)}{(y, y)} = \lambda_1(A)$$

Действительно, при всех $y \neq 0$
$$\frac{(\Lambda y, y)}{(y, y)} = \frac{\sum_{i=1}^n \lambda_i(A) y_i^2}{\sum_{i=1}^n y_i^2} \geq \frac{\sum_{i=1}^n \lambda_1(A) y_i^2}{\sum_{i=1}^n y_i^2} = \lambda_1(A)$$

Кроме того, если $y = e_1 = (1, 0, \dots, 0)^*$, то
$$\frac{(\Lambda y, y)}{(y, y)} = \frac{(\Lambda e_1, e_1)}{(e_1, e_1)} = \lambda_1(A)$$

Итак,
$$\min_{y \neq 0} \frac{(\Lambda y, y)}{(y, y)} = \lambda_1(A)$$

причём минимум достигается на векторе $y = e_1$. Приводя назад к $x$:
$$\min_{x \neq 0} \frac{(Ax, x)}{(x, x)} = \lambda_1(A)$$

При этом минимальное значение отношения Рэлея достигается, очевидно, на векторах $x = Ue_1$, т.е. на векторе, равном первому столбцу матрицы $U$. Но первый столбец $U$ есть собственный вектор $u^{(1)}$ матрицы $A$, отвечающий её наименьшему собственному значению $\lambda_1(A)$. Таким образом:
$$\min_{x \neq 0} \frac{(Ax, x)}{(x, x)} = \frac{(Au^{(1)}, u^{(1)})}{(u^{(1)}, u^{(1)})} = \lambda_1(A)$$

Рассмотрим теперь подпространство, составленное из векторов, ортогональных вектору $u^{(1)}$, т.е. таких векторов $x$, что $(x, u^{(1)}) = 0$, и найдём
$$\min_{\substack{x \neq 0 \\ (x, u^{(1)}) = 0}} \frac{(Ax, x)}{(x, x)}$$

Снова воспользуемся заменой переменных $y = U^*x$. Тогда
$$(x, u^{(1)}) = (Uy, Ue_1) = (y, e_1)$$

и условие $(x, u^{(1)}) = 0$ переписывается в виде $(y, e_1) = 0$.

Следовательно:
$$\min_{\substack{x \neq 0 \\ (x, u^{(1)}) = 0}} \frac{(Ax, x)}{(x, x)} = \min_{\substack{y \neq 0 \\ (y, e_1) = 0}} \frac{(\Lambda y, y)}{(y, y)}$$

В силу определения вектора $e_1$ условие $(y, e_1) = 0$ означает, что первая координата вектора $y$ равна нулю. Поэтому для всех $y$ таких, что $y \neq 0$ и $(y, e_1) = 0$:
$$\frac{(\Lambda y, y)}{(y, y)} = \frac{\sum_{i=2}^n \lambda_i(A) y_i^2}{\sum_{i=2}^n y_i^2} \geq \lambda_2(A)$$

Кроме того, если $y = e_2 = (0, 1, 0, \dots, 0)^T$, то
$$\frac{(\Lambda y, y)}{(y, y)} = \frac{(\Lambda e_2, e_2)}{(e_2, e_2)} = \lambda_2(A)$$

Отсюда следует, что
$$\min_{\substack{x \neq 0 \\ (x, u^{(1)}) = 0}} \frac{(Ax, x)}{(x, x)} = \min_{\substack{y \neq 0 \\ (y, e_1) = 0}} \frac{(\Lambda y, y)}{(y, y)} = \lambda_2(A)$$

причём минимальное значение отношения Рэлея на подпространстве $(x, u^{(1)}) = 0$ достигается на векторе $x = Ue_2 = u^{(2)}$, т.е. на собственном векторе, отвечающем второму по величине собственному значению $\lambda_2(A)$.

В общем случае совершенно аналогично показывается, что:
$$\min_{\substack{x \neq 0 \\ (x, u^{(1)}) = 0 \\ \vdots \\ (x, u^{(i-1)}) = 0}} \frac{(Ax, x)}{(x, x)} = \lambda_i(A), \quad i = 1, 2, \dots, n$$
Причём минимальное значение отношения Рэлея на подпространстве векторов, ортогональных собственным векторам $u^{(1)}, \ldots, u^{(i-1)}$, достигается на собственном векторе $u^{(i)}$, отвечающем собственному значению $\lambda_i(A)$. Данная формула - одно из вариационных описаний собственных значений симметрической матрицы.

## Принцип Куранта-Фишера
### Формула
$$\max_{R_{n-i+1}} \min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Ax, x)}{(x, x)} = \lambda_i(A), \quad i = 1, 2, \ldots, n$$
Пояснения:
- $R_{n-i+1}$ — любое подпространство размерности $n-i+1$.
- Сначала для конкретного подпространства $R_{n-i+1}$ ищется минимум отношения Рэлея по всем его ненулевым векторам.
- Затем берётся максимум этих минимумов по всем подпространствам данной размерности.
- Результат равен $i$-му собственному значению $\lambda_i(A)$.
Смысл:
- Принцип Куранта-Фишера даёт характеристику $\lambda_i(A)$ как наихудший случай (максимум) наилучшего приближения (минимум) среди всех подпространств размерности $n-i+1$.
Связь с первым описанием:
- Максимум достигается на подпространстве ортогональном первым $i-1$ собственным векторам, то есть на $R_{n-i+1}^* = \{x : (x,u^{(1)}) = \cdots = (x,u^{(i-1)}) = 0\}$.
### Вывод
На основе первого вариационного описания собственных значений выведем принцип Куранта-Фишера.

Сначала покажем, что если $S_i$ — подпространство, порождённое собственными векторами $u^{(1)}, \ldots, u^{(i)}$, то для всех $x \in S_i$:
$$\frac{(Ax, x)}{(x, x)} \leq \lambda_i(A)$$

Действительно, поскольку $x \in S_i$, то $x$ можно представить в виде:
$$x = \sum_{j=1}^i c_j u^{(j)}$$

Отсюда легко найти, что
$$(x, x) = \sum_{j=1}^i c_j^2$$ $$(Ax, x) = \sum_{j=1}^i \lambda_j(A) c_j^2$$
$$\frac{(Ax, x)}{(x, x)} = \frac{\sum_{j=1}^i \lambda_j(A) c_j^2}{\sum_{j=1}^i c_j^2} \leq \lambda_i(A)$$

Пусть $R_{n-i+1}$ — произвольное подпространство размерности $n-i+1$. Сумма размерностей подпространств $R_{n-i+1}$ и $S_i$ равна $n+1$, т.е. превышает размерность $n$ рассматриваемого пространства. Следовательно, эти два подпространства имеют нетривиальное пересечение, т.е. существует вектор $x_0 \neq 0$, принадлежащий как $R_{n-i+1}$, так и $S_i$. Из $x_0 \in S_i$ следует, что
$$\frac{(Ax_0, x_0)}{(x_0, x_0)} \leq \lambda_i(A)$$

Поскольку $x_0$ принадлежит и $R_{n-i+1}$, то
$$\min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Ax, x)}{(x, x)} \leq \lambda_i(A)$$

Напомним, что в качестве $R_{n-i+1}$ мы рассматриваем любое подпространство размерности $n-i+1$. Это неравенство справедливо для всех подпространств размерности $n-i+1$.

Заметим, что среди подпространств размерности $n-i+1$ есть такое, для которого это неравенство превращается в равенство. Согласно первому вариационному описанию таким подпространством является подпространство векторов, ортогональных собственным векторам $u^{(1)}, \ldots, u^{(i-1)}$. Таким образом, доказано, что
$$\max_{R_{n-i+1}} \min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Ax, x)}{(x, x)} = \lambda_i(A), \quad i = 1, 2, \ldots, n$$

Полученное вариационное описание собственных значений симметрической матрицы носит название вариационного принципа Куранта-Фишера.
### Следствия
**Следствие 1.** 
Пусть $A = A^*$, $B = B^*$,
$\lambda_1(A) \leq \lambda_2(A) \leq \dots \leq \lambda_n(A)$,
$\lambda_1(B) \leq \lambda_2(B) \leq \dots \leq \lambda_n(B)$
и пусть для всех $x$
$$(Ax, x) \leq (Bx, x)$$
Тогда справедливы неравенства
$$\lambda_i(A) \leq \lambda_i(B), \quad i = 1, 2, \dots, n$$

**Доказательство.** 
Согласно условию для всех $x \neq 0$
$$\frac{(Ax, x)}{(x, x)} \leq \frac{(Bx, x)}{(x, x)}$$
Отсюда следует, что для любого подпространства $R_{n-i+1}$ имеет место неравенство
$$\min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Ax, x)}{(x, x)} \leq \min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Bx, x)}{(x, x)}$$

Ясно, что и
$$\max_{R_{n-i+1}} \min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Ax, x)}{(x, x)} \leq \max_{R_{n-i+1}} \min_{\substack{x \neq 0 \\ x \in R_{n-i+1}}} \frac{(Bx, x)}{(x, x)}$$

Но согласно принципу Куранта-Фишера это неравенство может быть записано в виде:
$$\lambda_i(A) \leq \lambda_i(B), \quad i = 1, 2, \dots, n$$

**Следствие 2.**
Пусть $A = A^*$, $B = B^*$,
$$\lambda_1(A) \leq \lambda_2(A) \leq \dots \leq \lambda_n(A)$$
$$\lambda_1(B) \leq \lambda_2(B) \leq \dots \leq \lambda_n(B)$$
Тогда имеют место неравенства
$$|\lambda_i(B) - \lambda_i(A)| \leq \|B - A\|_2, \quad i = 1, \dots, n$$

**Доказательство.** 
Обозначим $C = B - A$ и рассмотрим выражение
$$(Bx, x) = ((A + C)x, x) = (Ax, x) + (Cx, x)$$
С помощью неравенства Коши-Буняковского оценим величину $|(Cx, x)|$:
$$|(Cx, x)| \leq \|Cx\|_2 \cdot \|x\|_2 \leq \|C\|_2 \cdot \|x\|^2 = (\|C\|_2 I x, x)$$
Отсюда
$$(-\|C\|_2 I x, x) \leq (Cx, x) \leq (\|C\|_2 I x, x)$$
и, следовательно,
$$((A - \|C\|_2 I)x, x) \leq (Bx, x) \leq ((A + \|C\|_2 I)x, x)$$
Согласно следствию 1:
$$\lambda_i(A - \|C\|_2 I) \leq \lambda_i(B) \leq \lambda_i(A + \|C\|_2 I)$$
или
$$\lambda_i(A) - \|C\|_2 \leq \lambda_i(B) \leq \lambda_i(A) + \|C\|_2$$
Отсюда непосредственно следует доказываемое неравенство.

Доказанное только что следствие 2 означает, что проблема собственных значений любой симметрической матрицы хорошо обусловлена.
